DAG Node 执行契约与路由

Node 是每个循环内部的最小控制单元：能重试、插入、跳过、gate、产出 artifact，也能把流程路由到其他循环的具体 Node。

Control Unit

DAG Node / NodeRun

Node 定义要做什么；NodeRun 记录一次执行、状态、输入输出、失败分类和路由建议。

Routing Rule
Node 不直接改 Mission 状态，只输出 route_recommendation

Process Orchestrator 读取 NodeRun 输出和 policy，决定重试当前 Node、跳到同 DAG 其他 Node、启动另一个 DAG 的指定 Node、创建子 Mission 或进入 human gate。

retry_node
重试

工具失败、临时环境问题、输出格式错误。

insert_node
插入补充节点

需要补充上下文、额外扫描或局部验证。

route_node
跨 DAG 路由

验证失败分流到探索、设计或修复节点。

gate_node
节点级审批

高风险工具、发布、schema、权限变更。

complete_node
完成并产出

写 artifact，推动 DAG 进入后续节点。

正式规则

A

NodeRun 输出建议，Orchestrator 做决定

NodeRun 是最小可观察与可控制粒度，但它不直接改变 Mission 生命周期；所有路由、重试、gate、跨循环跳转都由 Process Orchestrator 按 policy 执行。
