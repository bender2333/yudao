Mission 系统模块 v0.1

按职责拆模块：产品壳负责配置与观察，Mission Core 负责长期目标，Orchestrator 负责规则调度，Runtime 负责一次执行。

Module map
Product Shell
前端产品与协作入口
  • Mission Console：目标、循环、子 mission、当前状态
  • Agent Studio：固定角色、skills、plugins、env、model
  • Runtime Center：本地 daemon、云沙箱、CI、连接状态
  • Timeline：run、tool call、artifact、decision、approval
  • Autopilot：webhook、schedule、monitor trigger
Mission Core
长期目标与证据系统
  • Mission / SubMission / MissionRelation
  • Artifact：需求、设计、patch、测试、PR、告警
  • Decision：人审、策略选择、风险接受、回滚
  • Event：append-only mission event stream
  • Memory：可晋升的项目经验和流程经验
Process Orchestrator
业务无关流程管理员
  • Policy Engine：模式、gate、重试、升级、拆解
  • State Machine：mission lifecycle 和循环切换
  • Run Scheduler：选择 DAG template、agent team、runtime
  • Event Router：根据事件创建 run、子 mission 或 approval
  • Template Manager：流程模板版本和适用条件
EvoAgentX-style Runtime
一次性 DAG 执行层
  • DAG Template / DAG Run / Node Run
  • Agent / Action / ToolCall
  • Execution Environment 和轨迹记录
  • Runtime Adapter：Codex、Claude Code、Hermes、MCP
  • Run Result：结构化输出回写 Mission Core
Integration Layer
外部系统连接
  • GitHub/GitLab：repo、branch、PR、review
  • CI/CD：test、build、deploy、rollback
  • Observability：alert、log、metric、incident
  • Docs/Issue：Jira、Linear、飞书、Slack、Webhook
  • Secret/Vault：凭证注入和脱敏
Evolution Loop
评估与进化
  • Benchmark Dataset：从历史 mission/run 形成样本
  • Evaluator：质量、成本、风险、周期、稳定性
  • Optimizer：prompt、策略参数、DAG template 候选
  • Replay Sandbox：候选方案回放验证
  • Promotion Gate：人审后发布模板新版本

MVP 模块优先级

A

第一优先级：Mission Core + Orchestrator + Runtime + Tracking

先打通 mission 循环、一次性 DAG run、agent/runtime 配置和实时追踪；进化层先记录数据和评分，不自动优化。

B

第二选择：Product Shell 优先

更快形成可演示产品，但如果核心 run/event/artifact 没打通，容易变成静态看板。
