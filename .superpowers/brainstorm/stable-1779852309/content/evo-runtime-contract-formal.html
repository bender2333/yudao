EvoAgentX-style Runtime 执行契约

Runtime 只负责一次性 DAG run 的执行、轨迹、工具调用和结果回写；不负责长期 Mission 决策。

Hard Boundary
Runtime gives recommendations, not lifecycle decisions

Runtime 可以输出 recommended_next_action，但最终是否推进、回退、拆分、gate 或归档，只能由 Process Orchestrator 决定。

正式规则

A

Runtime = 一次性 DAG 执行器 + 轨迹与证据生产者

借鉴 EvoAgentX 的 WorkflowGraph、Agent/Action、Environment、Evaluator，但补上平台所需的持久化、权限、事件、artifact 和恢复契约。
