Mission 系统大架构 v0.1

核心定位：Mission 是长期演化容器；流程编排者只管规则；DAG runtime 负责一次性执行；产品壳负责展示、配置、追踪和协作。

Layered architecture
Product Shell - Multica-style
Mission Console / Agents / Runtimes / Approvals / Artifacts / Timeline

负责前端体验、配置入口、实时追踪、协作、任务时间线、agent/runtime 状态。

Core Domain

test / review / diagnose

Business-neutral Admin
Process Orchestrator = Policy Engine + State Machine + Run Scheduler + Event Router

只读取 mission 状态、证据、规则和 agent 结构化建议，决定下一步、gate、拆解、回退、升级、结束或沉淀。

Execution Runtime - EvoAgentX-style
DAG Run Engine / Agent-Action / Toolkits / Evaluation

负责一次性 workflow run：节点输入输出、agent/action、工具调用、轨迹、artifact 回写、评估记录。

Adapters
Codex / Claude Code / Hermes / MCP / GitHub / CI / Sandbox / Observability

连接真实执行环境、代码仓库、测试系统、发布系统、监控告警和外部工具。

Evolution Loop
Run History -> Evaluator -> Optimizer Candidates -> Sandbox Replay -> Human Gate -> Template Version

先生成候选优化，不自动改线上流程；优化对象是 DAG 模板、agent prompt、策略参数和工具组合。
