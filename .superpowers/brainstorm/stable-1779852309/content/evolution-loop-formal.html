进化循环

进化不是让系统直接自动改线上流程，而是基于 Mission / DAG / Node 历史形成评估、候选、回放和晋升机制。

Evaluation & Evolution loop
1 Data
Run History

Mission、DAGRun、NodeRun、Artifact、Decision、Feedback、Metrics。

→
2 Evaluate
Evaluator

质量、成本、风险、周期、稳定性、返工和轨迹质量评分。

→
3 Generate
Candidate

DAG 模板、Node、prompt、policy、tool 组合、agent skill 改进候选。

→
4 Promote
Replay + Gate

沙箱回放验证，人审后晋升为新模板版本。

Optimization Targets
可进化对象
  • DAGTemplate / Node 顺序
  • Node input/output contract
  • Agent prompt / instructions
  • Tool policy / tool selection
  • Autonomy policy thresholds
  • Failure routing rules
  • Evaluation metrics weights
MVP Boundary
先记录和建议，后自动优化
  • P0：记录 evaluation record
  • P0：展示 run/node 质量指标
  • P1：生成改进候选
  • P1：沙箱回放对比
  • P2：人审晋升模板版本
  • P3：受控自动进化
Hard Boundary
Evolution candidates are not production changes

Optimizer 可以生成候选，但必须经过 replay、指标对比、风险检查和 promotion gate，才允许成为新模板版本。
