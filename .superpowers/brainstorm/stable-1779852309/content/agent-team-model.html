固定角色，开放能力配置

MVP 不让用户自由发明团队拓扑，先提供一套稳定的软件交付 agent team。

Default software delivery squad
Intake
Product Analyst

需求澄清、验收标准、范围控制

Design
Architect

方案、风险、模块边界、迁移策略

Plan
Planner

任务拆解、依赖、并发度、gate

Build
Implementer

代码修改、脚本执行、调试修复

Quality
Reviewer

代码审查、风险发现、变更建议

Verify
Verifier

测试、构建、验收、证据收集

Release
Release Manager

PR、变更说明、发布 gate

Operate
Ops Responder

监控、告警分析、回滚建议、任务回流

每个角色可配置的能力

S

Skills

可复用方法包：代码审查规范、部署流程、框架迁移、故障排查手册、团队偏好。

P

Plugins

工具连接器：GitHub/GitLab、Jira/Linear、CI、监控、MCP、浏览器、数据库、云服务。

E

Environment

运行环境：仓库、分支策略、runtime、环境变量、凭证范围、沙箱与网络权限。
