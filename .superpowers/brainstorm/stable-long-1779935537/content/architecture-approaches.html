A. 分层编排架构（推荐）

大 lifecycle 管状态、策略、事件和审批；小 DAG run 负责一次 agent 执行；优化系统基于历史 run 生成新模板版本。

One Huge Workflow Graph
Requirement → Design → Code → Test → PR → Release → Ops → Fix → Test → Release...
回环、事故、审批、重试都塞进一张大图

B. 单一巨型 workflow

概念简单，但回环、异常恢复、版本和审计会很快复杂化；不适合长期平台。

Task Queue + Agent Runner
每个任务直接分配 agent 执行
