Central rule
MissionEvent 是 append-only 事实流

所有状态变化、run 启停、node 分流、artifact 生成、审批、反馈和进化候选都必须写 MissionEvent。当前状态可以是投影，但事实源是事件和制品。

Mission
长期对象

目标、状态、当前 loop、autonomy mode、owner、project。

Artifact
证据制品

brief、design、patch、test report、PR、incident、retro。

NodeRun
最小控制点

status、inputs、outputs、failure_classification、route_recommendation。

Decision
编排决策

action、reason、policy_refs、target loop/node、human_gate。

Action
OrchestrationDecision

数据模型确认

A

核心数据模型 = MissionEvent 事实流 + DAG/Node 执行记录

Mission Core 保存长期事实；Runtime 保存 DAG/Node 执行；Orchestrator 保存可审计决策；Evolution 保存评估和候选。
