承接“需求探索与瓦解”的 Mission Brief，把目标转成方案、计划和工程产物；每次执行由 EvoAgentX-style DAG run 完成。

  • Mission Brief
  • Scope Boundary

  • Acceptance Criteria
  • Repo / Service Context
  • Autonomy Mode / Policy
Loop

Design & Build

生成方案、做影响分析、拆任务、修改代码、运行最小本地验证、形成候选实现。

design_unclear → explore
plan_ready → implement
build_failed → fix
candidate_ready → verify
Outputs

  • Design Note
  • Implementation Plan
  • Patch Set / Branch
  • Changed Files Summary

ImplementationRun

DAG Run D
FixRun

构建失败、冲突、工具失败后的局部修复。

Progression Gate
Candidate Readiness + Autonomy Mode

不是所有实现都要人工确认。默认自主下，若候选实现完整、最小本地验证通过、风险未越界，则自动进入检查与验证；高风险变更或权限敏感操作触发 gate。

Back
回到探索

发现需求不清、范围冲突、关键假设不成立。

Loop
继续构建/修复

构建失败、patch 不完整、工具执行失败。

Gate
人工确认

架构大改、schema 变更、删除数据、外部发布。

Forward
进入检查与验证

候选实现和基础证据已准备好。
