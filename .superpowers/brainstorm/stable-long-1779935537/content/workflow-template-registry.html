Workflow Template Registry

Mission Planner is dynamic, but bounded by registered workflow templates.

Why
Controlled dynamic workflow generation

Dynamic: Mission Planner can generate the next workflow from feedback, events, and Mission state.

Controlled: v0.1 workflows come from templates, parameter binding, and bounded node composition.

Selection Flow
Planner pipeline
classify_current_situation
  -> match_trigger_conditions
  -> rank_candidate_templates
  -> check_required_inputs
  -> bind_specchange_or_create_draft
  -> bind_agents_and_runtimes
  -> produce_DAGRunPlan
