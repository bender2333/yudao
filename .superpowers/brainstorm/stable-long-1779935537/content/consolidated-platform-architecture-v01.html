AI/Agent Native Mission Platform: v0.1 Architecture

Mission-first, agent-native, closed-loop product evolution platform.

Positioning
What This Platform Is

A long-running Mission system for software/product evolution.

Agents are primary operators. Humans set intent, constraints, approvals, and corrections. The platform owns mission state, execution history, artifacts, routing, and learning records.

Layered Architecture
Product + Runtime + Orchestration
AI / Agent Native Interaction Layer

Evolution Loop

Mission Lifecycle
Four Recursive Loops
1. 需求探索与瓦解
clarify intent, assumptions, boundaries, acceptance, child missions
2. 设计与构建
design note, implementation plan, patch, PR draft
3. 检查与验证
tests, review, acceptance check, three-way failure classification
4. 运维与反馈
release, observe, incident, rollback, retrospective, new mission input

Each loop is executed by one or more DAG runs. The platform can route back across loops when facts change.

Roadmap
Two v0.1 Phases

v0.1A: Full-loop thin slice — entry agent creates Mission, loops execute through DAG runs, verification routes correctly, Web Console shows trace, evaluation records are stored.

v0.1B: Self-bootstrap — platform registers its own repo as a project and uses its own Mission/DAG/Node runtime to develop itself.
