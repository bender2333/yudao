执行者 DeepSeekRuntime / 2026-10-31 09:20 / 实现（`harness/fetch.py`，新模块，不导入 `environment.py`）：
- 只发 GET，只允许 http 与 https；地址里带凭据（`user:pass@`）直接拒绝，请求头固定为 `User-Agent: Yudao/<版本>` 与 `Accept`（文本类型），客户端不设 Cookie；`httpx.AsyncClient(verify=ssl_context(), follow_redirects=False)`，证书走系统证书库。
- 重定向自己跟随：`Location` 用 `urljoin` 解析成绝对地址，最多 5 次（`REDIRECT_LIMIT`），每一跳都先过地址规则再发请求。
- 下载上限 5 MB（`DOWNLOAD_LIMIT_BYTES`）：流式读，超过就截断并标记；总期限 30 秒（`TOTAL_TIMEOUT_SEC`）由 `asyncio.wait_for` 与每一跳的剩余时间共同限制；取消由 `asyncio.Event`（`stop`）与请求任务赛跑，取消时放弃请求并抛 `FetchCancelled`。
- 地址规则：`configure_service_address(host, port)` 记下服务自己的监听地址与端口（监听 `0.0.0.0`/`::` 时用 `psutil.net_if_addrs` 取本机全部接口地址），每个目标地址都解析成实际 IP 与端口逐个比较，命中就抛 `FetchRefused`（含重定向到它）。
- 内容：HTML 用 `html_to_markdown.convert_to_markdown` 转成保留标题、列表、链接与表格的文本；`text/*`、JSON、XML 原样；其他内容类型抛 `FetchFailed("unsupported content type: …")`。4xx/5xx 是成功的动作，状态码写在回执里，正文照常保存。
- 正文存成外部来源工件（`put_external_source`，来源、最终地址、状态码、内容类型、取得时间），回执带最终地址、状态码、内容类型、字节数、是否截断、摘要值、工件引用、重定向链与耗时。
