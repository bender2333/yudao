# 工单 #551 执行日记

## 任务目标
实现询问工具与一层询问分支（ADR-0036、三部门循环结构第 4.1 至 4.3 节）：
1. 新增询问工具 `ask`（三个部门均有，控制核心处理）与回答工具 `answer`（仅在询问分支中提供，产品可附 PRD 修订）。
2. 提问方在 `ask` 调用处暂停步骤循环等待分支回答，当前激活不结束。
3. 控制核心在被询问部门历史上开出独立 `session_id` 的询问分支，分支请求包含被询问部门已有历史、每步重新计算的状态与问题；分支内无 `ask` 工具。
4. 产品的回答可附 PRD 修订，通过版本核对后接纳新版本，提问方下一步收到新 PRD 版本并继续工作。
5. 被询问部门历史只多一条问题与回答记录，排除分支内部读取过程。
6. 工程/质检分支在检查工作区中运行，拒绝写入运行工作区、提交交付、缺陷记录与放行；产品分支仅允许提交回答。
7. 新增事件种类 `ask_started` 与 `ask_answered`，登记载荷合同与 `KEY_FIELDS`。
8. 新增事件序列场景 `ask_answer_with_spec_revision` 并建立基准。
