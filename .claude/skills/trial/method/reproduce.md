# 独立复现与证据复核

本段由新的代理执行。协调者只交本方法、问题编号、操作步骤、适用要求、待观察现象、触发条件、实例清单、输出目录与截止时间；观察者模型按运行配置选择。作者的分析、根因、修复方案与其他代理的结论留在作者一侧。

复现任务书从第一行到最后一行都只放观察者可读的内容。协调者的准备备注另存文件，不把「交接前删除本节」的段落混进任务书。

## 交接表

| 项目 | 内容 |
| --- | --- |
| 问题 | 稳定编号、现象与要求依据 |
| 实例 | manifest、服务地址、独立浏览器端口和启停命令 |
| 被测条件 | 与原现场一致的 wheel、提交、逐部门模型、窗口、输出上限与材料版本 |
| 操作 | 具体选择器、文字或坐标，输入从指定文件读取 |
| 触发条件 | 哪个事件或页面状态能证明已走到比较位置 |
| 留证 | 记录、导出、截图与文字路径，每次状态变化单独一行 |
| 时间 | 本项与整段截止时间，整段最多三十分钟，观察者不自行延长 |

先运行实例 Inspect，核对原现场与复现实例的部门配置。不一致时记录差异，交回协调者建立相同条件。旧实例已修复、模型不同或仅版本号相同，均不能证明是在原条件上复现。

协调者交接前准备好已核对的原 wheel、输入文件、版本与摘要。没有原包或无法确认版本时，停在准备，记录尚未执行或条件不同；发布脚本拒绝旧提交时，不换构建路径冒充原包。原任务版本与当前方法版本分别记录，不能给旧运行补贴当前任务集版本。

## 执行与结论

照步骤操作，记录是否到达触发条件和后续现象。时间用完就结束该项，不为等某种结果无限继续。环境问题、服务进程消失、工具没有返回分别留证。

每项选一个结论并引用证据：

| 结论 | 依据 |
| --- | --- |
| 复现到 `reproduced` | 同样被测条件到达触发点，又出现原现象 |
| 触发后未出现 `not_observed` | 同样被测条件到达触发点，观察到不同结果 |
| 未触发 `not_triggered` | 截止仍未走到比较位置，或前一步受阻 |
| 条件不同 `conditions_differ` | 包、模型、窗口、输出上限或材料不一致 |
| 证据复核 `evidence_review` | 只重读同一份导出、截图或文字，没有重新产生状态 |
| 尚未执行 `not_run` | 没有实际操作，说明原因 |

没有触发、没有重跑和同条件成功分别计数。有限样本只陈述次数；误报需要明确裁决，不能从一次未出现推出。

静态文字或布局可以先做证据复核，说明实际看到了什么及通道限制。相同错误 audit 读数重复出现不算独立视觉证明。

## 交付

写 `repro.md`：操作、实例身份、触发证据、实际现象、结论、时间与限制。交回本次产生的导出、截图；状态写到本轮 `result.json` 的 `reproduction`，协调者提供相应 [records.md](records.md) 格式片段。

凭据只从环境引用填入，文件记录引用名。自己启动的进程按实例清单收尾，原始归档保持原样。
