# 实验独立试用

调用：`/agent-trial <阶段运行清单绝对路径>`。

你是独立裁判，使用全新上下文；先读 `.claude/skills/trial/SKILL.md`、`docs/trial/tasks.md` 和运行清单。沿用当前任务集的版本和固定输入，不能硬编码旧版 `trial-tasks@2`。使用 `/trial` 的实际模型、浏览器、VLM、实例身份、记录、评分与复现工具；本技能只增加实验的权限和返回约定。

确认没有参与本轮实现、候选择优或编写评分基准。运行身份记录 main 完整提交、wheel SHA-256、技能提交、任务集、材料、评分器和模型。用可信 main 构建并从工作区外独立安装；检查实际导入路径，产品进程与候选都读不到隐藏检查材料。检查材料放在裁判独占目录，由系统权限保护。

按固定 F1/R1 输入完成试用。为每条验收要求保存事件 id/位置、接口请求与状态、截图及独立 VLM 读数，核对三者指向同一事项、版本与时刻。强杀重启、断网、需求变更在独立探索实例进行，记录真实 PID 与恢复前后状态，避免改变固定任务条件。过程与结果未知时保留未知。

调用 `/trial` 即按它的规则生成记录与试用帖；外部发帖权限由本技能调用 `/trial` 的实验授权提供。报告缺陷、缺项与受阻，保留原始导出和每次尝试。实现完成或 CI 通过都不能代替真实试用结论。

向协调者返回 JSON 文件：`{"status":"passed|failed|blocked","commit":"完整main提交","wheel_sha256":"摘要","evidence":"绝对目录","unresolved":[]}`。只有身份核对、全部固定验收、三角核对与已批准探索均有完整通过证据且 unresolved 为空时返回 passed。环境缺项返回 blocked；产品要求失败返回 failed。不得修改实现、测试基准、工单或关闭阶段。
