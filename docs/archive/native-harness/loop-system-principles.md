# Loop System 原理

## 0. 命名与范围

弃用"harness"和"动态harness"这两个词——前者容易被读成"一个套在模型外面的壳",后者容易被读成"一个会自己变形的黑箱"，两者都不准确。系统的本质是一个**状态机驱动的循环**：外层由确定性代码推进状态转移，LLM 只在被显式调用的、有边界的位置产出提议。"Loop System"这个名字直接描述这个事实，不额外承诺任何东西。

本资料只回答一个问题：**如何让 LLM 驱动的系统，在一个已知的问题分布里，可靠地执行、自我修正、并渐进积累经验。**不回答"系统如何自主生成全新的、值得追求的目标"——这是一个量级更大、目前无人有解的问题（第 14 节详细说明边界，不在这里展开）。

---

## 1. 要防的两个病，以及它们的共同根源

**过早停止**：模型倾向于在没有真正满足约束的情况下宣布完成，尤其是自己评审自己的时候。

**上下文污染**：无论是单一会话的自我合理化，还是多版本历史的并列陈列，都会导致确认偏误、时间错位损伤、判断漂移。

这两个病看似独立，根源相同：**ReAct 结构里，决策、执行、验证塌缩成了同一个模型在同一段连续上下文里做的同一件事。**模型自己生成动作，自己（在同一段文本流里）判断这个动作对不对、该不该继续。没有一个独立于生成过程的裁决者。

---

## 2. 核心不变量：U ≠ f

无状态 LLM 可以形式化为一个转移策略生成器 f，Harness 保存状态 Sₜ，执行：

```
Sₜ₊₁ = U(Sₜ, f(P(Sₜ)))
```

P 负责从外部状态构造提示词，f 是 LLM 的输出，U 是校验并应用这个输出的裁决者。**ReAct 的病根是 U 和 f 塌缩成了同一个东西**——模型的输出被直接、无中介地执行。

整个系统只有一条最高优先级的不变量：**LLM 只能提议状态变化，不能直接宣布状态已经改变。**

由此推出一个容易被误解的结论：**ReAct 没有被消灭，只是被限定了作用域。**单次 Session 内部——观察一点东西、决定下一步动作——这个局部结构永远是 ReAct，而且大概率永远该是。真正的架构升级不是"用别的东西替代 ReAct"，是把 ReAct 从系统的**控制流**降级为一个被调用组件的**内部实现细节**，外层的状态转移由不含任何 LLM 调用的确定性代码计算。

---

## 3. 图灵完备是廉价的，可靠性才是稀缺的

无状态 LLM + 外部持久状态 + 无界迭代，在理想模型下已经图灵完备——这个结论证明起来不难，且**图灵完备性主要来自 Harness，不来自 LLM**：把 LLM 换成任意函数，只要转移规则被精确执行，系统依然完备。这意味着**架构升级不能靠"让系统能算更多东西"来证明自己有价值**——单层系统的计算能力早就够了，再往下拆解不会突破任何计算能力的天花板。

真正稀缺的是可靠性。假设每一步独立正确的概率是 p，一个需要 N 步的任务，无恢复成功率近似为 P_success ≈ pᴺ。这个公式说明的不是"复杂系统会出错"，是**单步可靠性会在循环里复利**：0.95¹⁰⁰≈0.006，0.999¹⁰⁰≈0.905。现实错误不独立，但核心现象成立——**一个聪明但协议执行不稳定的模型，可能远不如推理稍弱但协议服从度高的模型。**

这条原理决定了一个判断标准：任何新增的结构（分层、递归、多角色），必须能明确指出它在拦截哪一类现有结构拦不住的错误，否则默认不加——加一层的成本是确定的（token、延迟、维护），收益是概率性的、边际递减的。

---

## 4. 分布式校验有效的真实条件是错误独立，不是结构对称

多头/多带图灵机的等价性证明，发生在一个**每一步都精确无误**的模型里——图灵机没有错误这个概念，多一个头看到的是同一份精确无误的过程，不产生新信息，所以多带机只影响复杂度、不影响可计算性（标准结果：k 带机可被单带机以 O(f(n)²) 模拟，多项式开销，不是指数级差异，更不是"没有区别"）。

用这个定理去回答"多角度审查有没有用"，是用错了工具——LLM 系统的每一步不是精确无误的，错误率 p<1 才是真正的自变量，而这个变量在图灵机等价性定理里根本不存在。

真正决定多角度审查有没有用的，是**错误的相关性**。如果 N 个角度的漏检概率独立，全部漏检的概率是 p_miss^N——真实的、乘性的可靠度收益（RAID、纠错码、多数表决用的是同一个原理）。如果 N 个角度其实是同一个模型、同样的训练偏差，只是提示词换了说法，错误高度相关，p_miss^N 不成立，加头没有实质收益。**三部门（需求/开发/质检）之所以有效，是因为目标函数真的不同（挑错 vs 完成）、证据来源真的不同（跑测试 vs 自己写代码）——是角色分化，不是结构自相似。**任何"分形"如果说不出这一层新增的独立性具体是什么，就是在复制粘贴形状而没有复制粘贴原理。

---

## 5. 谁验证验证者——这是个结构性问题，没有免费解

信任链必然有一个终点：质检部有开发部（澄清单）纠偏，开发部有质检部纠偏，质检部自己没有对称的机制。这不是设计疏漏，是任何分层校验系统的结构性必然——**再往外套一层验证者，问题原样复现在新的一层，不会被消灭，只会被挪位置。**

处理方式不是消灭这个终点，是让终点的错误变得**可观测、可反馈、但不产生新的未经检验的权威**：独立抽样复核（不是全量审查，防止复核者自己变成新瓶颈），复核结果不直接否决原判断（否则复核者取代了原判断者的位置，问题没解决只是搬家），而是把"复核与原判断的不一致率"作为一个信号，反馈给一个**只调整参数、不做判断**的控制层——不一致率高，就提升审查密度，而不是引入新的裁决权威。

这个结构性障碍在证明驱动的自我修改理论里有更精确的数学刻画：Löb 定理说明，一个形式系统无法仅凭自身证明系统，确认另一个和自己同构的系统"可靠"这件事——这是**为什么完全形式化的自我验证存在天花板**的原因，不只是工程经验，是定理。

---

## 6. 上下文不是历史，是可复用的当前态 + 外置事件

**并列陈列旧版本 = 污染，这是实证结论，不是猜测。**模型面对并列矛盾信息表现出确认偏误——把旧版本当成候选事实参与采信竞争，而且竞争结果受表层特征（如实体流行度）影响，不按时间先后；时间错位本身（不把历史标记为"已过期"）是独立的性能损伤源。三个独立阵营（Anthropic 的 context engineering、Zep/Graphiti 的双时态图、Mem0 的 ADD/UPDATE/DELETE/NONE）收敛到同一个形态：**上下文内 = 唯一活态 + 极薄因果注记；历史 = 外置事件化存储，按需检索，带失效注记。**

同样重要但更容易被忽略的一点：**单一会话内部的单调累加，本身也是污染源**，不只是跨版本陈列。对同一问题纠错超过两轮，上下文已经被失败尝试污染，正确的处理不是继续在同一段上下文里挣扎，是**检查点驱动的会话重启**——蒸馏出结构化的经验记录，旧会话整体标记失效并封存（不删除，可按引用取回，但默认不再注入），新会话只带当前态与蒸馏出的经验重新开始。

---

## 7. 递归的正确态度：有界、触发式，不是设计时的固定形状

"能不能一直递归"是个平凡问题——能，任何可组合系统都能这么嵌套。真正的问题是**在哪停**。

递归的默认后果不是更可靠，是把"计算"错误地升格成"事实"：内层原本可以随便浪费的试错噪音，一旦被正式化成工单、因果链、版本号，就从可丢弃的计算，变成了必须维护的状态——你在更细的粒度上，重新制造了上一层刚解决掉的污染问题。而且这个后果会自相似地向上传播：如果允许多层递归，会得到一棵因果链的**树**，不是一条**链**，任何想审视全局的角色（Council 一类），现在要面对的不是一条 ≤10 行的更替链，是一棵嵌套因果链的树——递归每加一层，可审计性掉一个数量级。

因此：**深度必须有硬上限**，触发递归的信号必须是代码可判定的、运行时观测到的挣扎证据（Session 自身预算耗尽未收敛、同一对角色间往返超阈值、改动范围超历史基线），不能是模型自己判断"这里很复杂该拆了"。而且每一层新增的递归，必须自带自己的因果链压缩机制，不能假设"外面会想办法看"——没有这条，递归深度每加一，可审计性就掉一个数量级。

## 8. 控制论视角：动态分两种，风险完全不同

开环系统不会适应变化，但也不会因为自己的反馈而发散——它没有反馈回路可以失控。闭环系统能纠正开环系统纠正不了的扰动，前提是反馈回路本身**稳定**——负反馈、有界增益。控制论里最基础的失败案例就是增益过高或延迟过长的控制器：不但不会更稳，反而震荡甚至发散——这是闭环系统特有的、开环系统结构上不可能出现的失败模式。

**"动态"不是稳定性的充分条件**，必须分两种情况判断：

- **调整回路内部的有界参数**（触发阈值、预算分配比例、检索权重）——标准自适应控制（self-tuning regulator / MRAC）范畴，回路的锚点（谁有权、目标是什么）完全不动，控制器只根据观测数据调整自己的增益。这条安全，而且天然自限——调错了，下一个观测窗口的新数据会把它纠回来。
- **调整回路本身的结构**（谁有权拒绝谁、验收标准算不算数、角色边界怎么划）——这是在调整锚点本身。一旦"目标是什么、谁有权拒绝谁"这个反馈回路的参照点，被拿到回路内部，让系统用自己的自我评价去调整它，系统对自己的判断如果有任何系统性偏差，这个偏差不会被纠正，只会被放大——因为已经没有回路外的东西能拦住它。

第一种可以放心做，是长期运行系统应该有的能力。第二种如果要做，必须先有一个不受这次调整影响的外部锚点，不能假设"反正是动态的所以会自我修正"——这句话在控制论里不是定理，是需要专门设计才能兑现的承诺。

## 9. Autopoiesis：身份由组织闭包决定，不由材料决定

一个系统持续替换自身组成部分、同时维持组织结构不变，其**身份**由它的**组织闭包**（系统自身产生并维持自身组件这个循环关系）决定，不由具体哪些材料构成决定——这是忒修斯之船在系统论里的正式版本。

翻译成设计规则：**只要组织闭包保持不变，材料层面（工具实现、模块内部逻辑、甚至权重本身）的渐进替换不改变系统身份。**组织闭包由四条不变量构成，这四条是任何自适应机制都不能触碰的边界：

1. **目标层不可变**——goal / constraints / acceptance_criteria 只能被用户显式批准修改。
2. **权威拓扑不可变**——谁能拒绝谁，是设计时定死的常量，不是运行时可协商、可学习的东西。
3. **U ≠ f 不可变**——任何状态提交动作必须经过非 LLM 的裁决。
4. **失败即失败不可变**——撞安全上限记失败，不能被自适应层悄悄放宽成"再给一次机会"。

诚实的边界：即使在生物学原生领域，autopoiesis 能延伸到细胞之外多远，本身也有争议（Luhmann 将其延伸到社会系统时，在系统论内部引发了持续的争论）。把它从"细胞"搬到"工程系统"，和把图灵机理论从"符号系统"搬到"连接主义大模型"是同一类风险的动作——都是跨基质的类比迁移，需要交代清楚"保留了什么本质、丢弃了什么"，不能默认成立。

## 10. 主动推断：检查点该设在哪，有第一性原理的答案

惊讶（surprise）= −ln p(o)，观测在系统自己的生成模型下越不符合预期，这个值越大。自由能是这个不可行量的一个可计算变分上界。主动推断给出一条具体的工程指导：**精度加权**——系统不该对每一次观测都同等更新，该在预测误差高的时刻更多更新，预测已经准确的时刻少更新甚至不更新。翻译成检查点设计：**校验密度该往预测误差高的地方集中，不该均匀撒在固定步数上。**

**Dark room problem**是必须知道的退化解：如果目标单纯是最小化惊讶，最省事的解法是待在一个完全可预测、什么都不会发生的地方——退化解是回避一切不确定性，不是"表现得更好"。这正好是过早停止在验证侧的镜像故障：从"提前宣称完成"变成"提前规避有风险的探索"。修正方式是把目标分解为**实用价值（朝目标状态走）+ 认知价值（主动寻求信息、降低不确定性）**，只优化前者会导致躲进暗室。

诚实边界：自由能原理本身有可证伪性争议——数学结构足够通用，通用到几乎任何持续存在的系统都能被事后重新描述成"在最小化某个自由能"，这不是 Rice 定理那种干净利落的硬边界，是一个解释性框架，边界条件不清楚。用它指导具体设计决策没问题，不要指望它提供数学证明级别的保证。

## 11. Open-endedness：新颖性单独使用会退化

Open-endedness 的定义要求两个条件同时满足：**新颖性**（对观察者越来越难预测）+ **可学习性**（观察者通过学习过去的产物，能逐渐更好地理解新产物）。

单独使用惊讶信号检测新颖性，最优解不是"发现有意思的新东西"，是**钻进任何一个产生高熵输出的地方，然后待在那里**——纯噪声对任何预测模型都是最难预测的，这就是 noisy TV problem。这是 dark room problem 的镜像故障：一个纯粹最小化惊讶,退化成缩进绝对可预测的角落;一个纯粹最大化惊讶，退化成钻进绝对不可预测的噪声源。两者的病根相同：**单一标量的惊讶信号，不管往哪个方向优化，都没有能力区分"结构化但暂时未知"和"纯粹随机、永远不可知"。**

可学习性弥补的正是这一点，但它是**轨迹量**（预测误差随样本数增加是否系统性下降），不是**时刻量**（单次预测误差有多大）——不能靠给惊讶信号加权重间接获得，需要一个独立的、按 scope 追踪趋势的机制。

再往深一层：这套联合信号解决的是"检测新颖性"这个问题，不解决"评判新颖性的这把尺子本身要不要、能不能自主进化"这个更深的自指问题——这个问题和第 5 节"谁验证验证者"是同一个数学形状，只是这次没有一个已知的、可操作的绕行方案。这是项目二（自主生成全新目标）的领地，不在本资料的覆盖范围内。

## 12. 为什么可学习性判断不能交给 LLM 直接做

短序列趋势判断——这是不是真实趋势，还是纯粹噪声——是人类认知里一个专门被记录过的系统性失败范畴（小数定律、热手谬误）。这不是"人类比较笨、LLM 会更准"的问题：任何靠模式补全/叙事连贯性做判断的机制，不管载体是人脑还是 LLM，在这类任务上都会系统性地被噪声欺骗，因为这类机制的天性是找一个说得通的故事，而短序列里几乎总能找到一个说得通的故事，不管背后有没有真实趋势。

趋势判据必须落回可复现的非参数统计检验（如 Mann-Kendall / Spearman 秩相关，对小样本、有噪声的序列本来就是设计来用的）。LLM 在这条流水线上唯一站得住脚的位置，是在趋势已经被代码算出来之后，生成一个候选解释——且这个解释必须被明确标记为**未经验证的候选叙事**，不能被系统当作新事实写回状态或触发下一步动作。

---

## 13. 学习的分层结构：稳定性-可塑性困境

一个系统要足够可塑才能学新东西，要足够稳定才能不冲掉已学会的东西——这两个要求对同一组共享参数是相反的（stability-plasticity dilemma）。如果每次惊讶信号都直接触发权重更新，会陷入灾难性干扰：新样本的梯度覆盖掉和它无关的旧知识。

**这不是资源不够时的将就方案，是理论上本来就不该让每次惊讶直接写权重**——生物系统对这个问题的答案是分成两套系统：海马体负责快速、单次、情景式编码；新皮层负责慢速、需要多次重复、高度泛化的巩固存储；海马体记下的东西不是直接写进皮层，是在离线阶段被回放，让皮层用很小的学习率、掺杂大量已有知识一起慢慢吸收（Complementary Learning Systems 理论）。哪怕算力无限，理论上正确的做法依然是分两套系统，不是让慢系统承担全部。

四层映射，更新速率随层级单调递减，可逆性随层级单调降低，门禁随层级单调收紧：

| 层级 | 生物学对应 | 更新方式 |
|---|---|---|
| 控制回路增益（触发阈值、预算分配） | 稳态调节 | 最快，自限，可自动回滚 |
| Lesson card | 海马体（情景记忆） | 快，单次编码，可失效 |
| Skill / schema | 海马体→皮层过渡（schema 一致性快速学习） | 较慢，需跨样本反复验证才"毕业" |
| 权重 | 皮层（巩固存储） | 最慢，离线批量，掺混重放，门禁最严 |

Schema 一致性学习（Tse et al. 2007）给出一个具体机制：如果新信息和已巩固的骨架相容，可以绕过慢速巩固直接快速写入——"高阶 skill"如果定义为"被多条 lesson 反复验证、跨越多个场景都成立的模式"，它已经具备了这个"够资格被快速写入"的前提，因为它已经被大量情景证据预先筛选过，不再是单次样本的噪音。

## 14. 诚实的边界

**本资料覆盖的问题（项目一）**：LLM 驱动的系统如何在已知的问题分布里，可靠地执行、独立地自我验证、渐进地积累和巩固经验，并且这套机制本身可审计、可回滚、不会随时间推移而失稳。这个问题有站得住的答案，第 1–13 节是这个答案的理论支撑。

**本资料不覆盖的问题（项目二）**：系统如何自主地突破当前的问题分布本身，生成真正意义上全新的、有价值的目标和技能空间——这是 Recursive Superintelligence 尺度的野心。它最终会撞上和第 5 节、第 11 节末尾同一个数学形状的自指问题：**用什么去验证"用来验证新东西是否有价值的那把尺子"本身在变好**——这个问题目前没有已知的、可操作的解，不是本系统的设计缺陷，是这个领域今天实际站着的前沿边界。知道边界的形状，本身就是有价值的信息，不需要在没有答案的地方假装有答案。
