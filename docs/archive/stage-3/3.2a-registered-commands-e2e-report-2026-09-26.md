## 2. 运行记录

### 2.1 run_c4e724a13fb14af0：发现适配器缺陷

产品部门第二次模型请求得到上游 HTTP 400，运行以 `FAILED / provider_error` 结束（26 条事件）。把应用捕获的请求原样回放给上游仍为 400；去掉重复的工具结果后为 200。原因是 Chat 与 Messages 适配器在已装配 input 之外再追加一遍工具结果，同一 `tool_call_id` 出现两次；两个适配器另外上报一条聚合消息观测，作为无类型条目进入部门历史，Chat 回放时翻译成空的 user 消息。修复与测试见提交 800c5bc 与 `harness/tests/test_protocol_history_replay.py`。
