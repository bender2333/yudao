## 动态 Harness 理论架构基线

基于当天关于 RSI、Active Inference、稳定性-可塑性、分层预测编码和复杂度控制的讨论，新增：

- `CONTEXT.md`：固定 Dynamic Harness、Prediction Commitment、Surprise Profile、Episode、Lesson Card、Schema、Skill、Fold/Unfold、Change Candidate 与 Organizational Closure 等领域语言。
- `docs/native-harness/dynamic-harness-architecture.md`：目标系统的理论架构、模块接口、工件协议、候选生命周期、失败防线与分阶段验证路线。

本次定下的关键判断：

1. Dynamic Harness 是受治理的复合自适应系统，不是把 ReAct 或三部门循环无限递归。
2. Surprise 是带精度和作用域的诊断信号，不是系统宪法；目标与授权继续来自外部治理。
3. 冻结 LLM 权重不妨碍系统学习，外部知识、Context、Router、Skill 和 Topology 都是正式学习载体。
4. Lesson Card 是可证伪假设，不因一次 QA 拒单自动取得跨任务策略权；Episode、Lesson、Schema、Skill 分层晋升。
5. 稳定 Harness 子图通过 Fold 成为 Skill，异常时通过 Unfold 恢复内部结构；复杂度压缩必须可逆。
6. 递归统一的是 Harness Node 外部契约，内部收敛机制保持异构，并由确定性权限和预算封顶。
7. Meta-Controller 只选择响应，Consolidator 只生成候选，活动权必须经过独立评价、授权和 Change Manager 晋升。
8. 渐进 RSI 采用新旧版本并存、影子比较、局部切换和回滚；宪法主权、独立评价、证据连续性与回滚可达性构成组织连续性。

范围声明：本文档轨与当前 S/T 对比实验并行，不修改已批准协议，不运行 Harness live 模型或实验，不构成实现授权。下一步架构题是 D1 + O0/O1 Observer 基础协议。

## Open-endedness 纳入学习核心

用户补充 DeepMind 2024 对 Open-endedness 的定义后，按一手来源核验并新增 `docs/native-harness/2026-08-11-open-endedness-research.md`。严格定义要求 Artifact 序列相对指定 Observer 同时满足：未来持续存在更难预测的 Artifact，以及增加历史后对同一未来 Artifact 的期望预测损失严格降低。

由此修订架构：

1. 原来的单一误差收敛回路拆成运行环与发展环。运行环负责交付、修正和 Fold；发展环负责生成新 Artifact、维持可学习新颖性前沿。
2. 新增 ArtifactArchive、DevelopmentalObserver 和 OpenEndednessMonitor；Artifact、Observer、Loss、Artifact Schema、训练前缀、评价后缀和时域都必须版本化。
3. Open-endedness 是长期发展动力，不是业务价值函数。Novelty 单独会奖励噪声，Learnability 单独会收敛到固定分布；正确性、安全和生产晋升继续由独立评价与治理决定。
4. 生产作用域保持唯一活动版本，发展 Archive 允许多分支和生态位并存；发展产物只能作为 Change Candidate 进入生产。
5. 有限实验只能报告相对 Observer、Loss 和时域的 finite open-endedness evidence，不能宣称复杂度数值无界或系统永久开放。
6. 内部 Observer 会反过来影响生成器，因此只算 proxy observer，不能同时充当无偏最终证明者。

下一步文档题调整为 D1 + O0/O1 Observer 基础，仍然只观察，不改变执行策略。

## 架构只读审查与验证

独立只读审查发现并关闭三处权威漏洞：

1. Canary 原先可能在完整授权前接触真实流量。现改为进入 Canary 前必须取得绑定作用域、分片、期限、预算、停止门和活动基线的限域授权。
2. ChangeManager 原先直接接收 Evaluation/Authorization 对象，调用者可伪造或错配。现只接受可信 Ledger 引用，并校验签发者能力、候选哈希、scope、评价规格、时效和撤销状态。
3. HarnessRuntime 原先允许调用者传 `TopologyRef`，可绕过唯一活动版本。现外部 `execute` 不接拓扑，Runtime 只执行 ChangeManager 解析出的不可变 Execution Grant。
