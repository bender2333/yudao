   - 两条的 `flow_id` 是事件编号加接收部门（`evt_xxx:engineering` 与 `evt_xxx:quality`）：同一个事件的两条不能用同一个编号，否则后一条会盖掉前一条。
   - 推导版本由 1 加到 2：服务打开读取模型时发现保存的版本与代码不同，就从事件重放重建一次（旧行不会自己跟着变，工单 #684 的做法）。
