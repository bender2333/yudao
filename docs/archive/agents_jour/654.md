2. 实现：

   - `harness/projection.py` 与 `harness/models.py` 没有改，没有新增字段；客户端没有改（`materials.tsx` 的 `VersionBlock` 原样显示 `entry.status`）；接口合同没有变，`API_VERSION` 没有提高。
3. 测试：
   - 新增 `harness/tests/test_materials_status.py`：场景是产品提交第一版 PRD、工程发问、产品在回答里修订 PRD（第二版并重新接纳）、工程交付、质检放行——这样这个 run 里有两版 PRD 与两份有效合同。核对三件事：投影里两版 PRD 的状态是 `["superseded", "active"]`；资料页 PRD 一节两版合同的状态是 `["superseded", "active"]`；交付一节用同一套词。
   - 反向验证：把合同的状态改回写死的 `"active"`（工单正文说的旧写法）后重跑，用例失败并给出 `['active', 'active'] == ['superseded', 'active']`，正是用户走查看到的现象；改回后通过。
