   - `client/src/renderer/src/views/models/model-logic.ts`（工单「只改」清单里没有，理由写在工单评论里）：两个纯函数 ✓——`jsonDialogFailureText(error)`（失败提示，失败原因原样带出 ✓；没有失败时没有提示 ✓）与 `canSaveDocument(text)`（空文档不让保存 ✓）。放在这里是因为弹窗是 `.tsx` ✓，单元测试不能直接引入 ✓（node 的类型擦除不支持 JSX ✓），纯逻辑要在 `.ts` 模块里 ✓。
