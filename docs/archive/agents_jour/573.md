# 工单 #573：资料页的建档各轮与轮次定位

## 背景与任务

从 #138 拆出（父工单 #124）。按接入已有项目设计说明第 3.4、4.7 节与原型 v8 设计说明第 7.3 节，在资料页加入建档各轮：每一轮的初始 PRD 原文与确认记录；项目材料中的现有结构说明、基线核验与基线检查。决定卡片上的 PRD.md 与 STRUCTURE.md 链接带上卡片的轮次，资料页据此定位到那一轮（在可见区域内）。

任务范围：
- 只改 `client/src/` 与 `client/tests/`，以及联系表输出 `docs/stage-3/contact-sheets/573/`。
- 不改后端、不改接口合同、不改决定卡片其他部分与概览。

## 实现细节

1. 路由与路径（`client/src/renderer/src/shell/routing.ts`）：
   - `Route` 类型增加 `round: number | null` 字段；
   - `parseRoute` 从 URL 查询参数 `round` 解析正整数轮次；
   - `paths.materials` 支持可选的 `options: { workItem?: string | null; round?: number | null }`。

2. 卡片逻辑（`client/src/renderer/src/views/decisions/card-logic.ts`）：
   - `materialsHref` 在请求载荷存在数字 `round` 时，为资料页路径附加 `round` 查询参数（`#/p/${project}/materials?w=${workItem}&round=${round}`）；
   - `card-logic.test.js` 断言初始 PRD 的两个工件链接带上轮次，并增加无轮次回落测试；`routing-replay.test.js` 增加 `round` 解析与 `paths.materials` 构造测试。

3. 资料页与样式（`client/src/renderer/src/views/project/materials.tsx`、`client/src/renderer/src/styles/v10-project.css`）：
   - `OnboardingBlock` 为每一轮的 `<li>` 赋予 `id={`onboarding-round-${round.round}`}`；
   - `MaterialsPage` 监听路由中的 `props.route.round`，在数据就绪时定位并滚动目标轮次到可见区域（`scrollIntoView({ block: "start" })`）；
   - `.y10-mt-doc` 样式增加 `scroll-margin-top: 76px`，避免滚动定位时被吸顶顶栏遮挡；`.y10-mt-doc .y10-pre` 设置 `max-height: 240px; overflow: auto;`，确保 1440×900 视口下同轮的初始 PRD 与结构说明能同时处于可见区域内；
   - `BaselineReviewBlock` 增加 `baselineCheckRow` 格式化基线检查，包含名称（`name`）、命令（`command`）、退出状态（`退出状态 ${exit_code}`）与摘要（`summary`）；
   - `DecisionRecords` 增加 `decisionOptionLabel` 映射，将选项代码 `revise` 格式化为「提出修改」、`confirm` 为「确认」。

4. 端到端测试（`client/tests/e2e/onboarding-prd.spec.ts`）：
   - 完善「初始 PRD 的资料（1440×900）」用例：接入后提出修改等到第 2 轮决定卡片；
   - 分别从第 2 轮卡片的 `PRD.md` 和 `STRUCTURE.md` 进入资料页，通过 Playwright 的 `toBeInViewport()` 断言第 2 轮的「初始 PRD」与「现有结构说明」均在可见区域内；
   - 逐轮核验第 1、2 轮的内容完整性（初始 PRD 原文、结构说明、基线核验结论、基线检查名称/命令/退出状态、其他失败），核验第 1 轮确认记录为「回答：提出修改」与修改意见原文、第 2 轮给出上一轮修改意见、第 2 轮 PRD 原文来自第二轮 ProductSpec 且与第 1 轮不同；
   - 1920×1080 宽屏用例核对水平无滚动且控制台零错误。

5. 截图联系表（`docs/stage-3/contact-sheets/573/`）：
   - 执行 `node scripts/build-page-contact-sheet.mjs --issue 573 --pages materials` 生成浅色与深色对比表及 `index.md`。
