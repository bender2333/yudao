# V14 原型运行约定

双击 `index.html` 即可打开，默认进入 `#/sys/models`。也可以在仓库根目录运行：

```powershell
uv run python -m http.server 8914 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8914/docs/prototypes/v14/index.html#/sys/models`。

V14 的增量文件：

| 文件 | 作用 |
| --- | --- |
| `index.html` | V13 外壳的 V14 入口，替换模型管理页面脚本，加载新增样式 |
| `js/bootstrap.js` | 内存存储、V14 标识、默认模型路由、默认收起原型工具条 |
| `js/ui/views/sys-models.js` | 模型管理交互、候选示例、自动配置与异常场景 |
| `styles/models.css` | 使用 V13 色板和组件的增量布局 |
| `assets/` | 沿用 V13 的六张截图，供其他页面按原路径打开 |

公共脚本与样式引用 `../v13/`，因此移动或分享时保留相邻的 V13 目录。V13 的全局对象与 CSS 类名继续使用 `Y13`、`y13-`；V14 模型脚本通过 `window.Y14` 接入。行为与限制见 [design.md](design.md)。

浏览器走查覆盖正常配置、139 个候选的搜索筛选、参数展示、部门切换、刷新保留、更换凭据使旧准入失效、失败恢复、空列表、模型权限拒绝、容量未知、取消后的异步结果，以及 390 / 1440 像素宽度。原型采用示例数据，这些结果仅验证页面交互。
