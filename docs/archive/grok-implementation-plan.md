## 执行规则

- 主 agent 负责架构、审查、验收和日记，应用代码交给 Codex 子 agent，按文件责任并行。
- 沿用当前原生运行器及未提交改造；OMP 仅代码参考，不合回规划树旧业务代码，不增加兼容层、迁移或回退。
- 每批保持可运行，同步必要 Web 观察与实际输入审计；验证通过后及时 commit、push。
- 次数、超时与取消继续；provider 用量只读。原始历史完整保留，摘要有来源、可取消且计步骤。
- 实现、验证、原生内核完成和第一阶段整体完成分别报告。
