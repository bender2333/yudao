## 结论

根因是应用构造错误。`submit_product_spec.parameters.change_record` 使用 `anyOf: [{type:null}, {type:object,...}]`，没有顶层 `type`。当前 Responses 目标 `https://penguinapi.vip/v1` + `gemini-2.5-flash` 返回 HTTP 400、`invalid_request_error`。

最小修正：把 `change_record` 改成可选 object（不在 required 中）。未换服务、模型或 Prompt，未加协议 fallback，未给 400 增加原地重试。

HTTP 错误诊断同时补了有界脱敏字段：`status_code`、`error_code`/`error_type`/`param`、`request_observation_id`。不保存错误原文或 message。
