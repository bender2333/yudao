# 一份连接只声明一种协议

调用协议属于 Provider 配置。一份连接只声明一种协议。同一服务方案要使用另一种协议时，另建一份连接。服务方案按协议列出请求基址；选定协议后，连接地址取该协议的请求基址，请求路径由该协议的适配器按协议规范拼接。模型访问定义不单独声明协议。厂商只作为服务方案的命名与来源出现，不出现在字段里。

同一订阅往往要同时使用 Responses、Chat Completions 与 Messages。把协议放在连接上，更换协议就再添加一份连接，配置页可以按连接收起模型。请求基址的用法与 OMP、opencode 及各官方 SDK 相同：OpenAI 的两种协议在基址后拼接 `/responses` 或 `/chat/completions`，Anthropic 协议去掉基址末尾的 `/v1` 后拼接 `/v1/messages`。

修改协议后，该连接下的准入作废，部门默认与项目部门设置中指向这些访问定义的引用保留并显示无法使用。同一服务方案的另一份连接默认使用同一凭据引用，也可以改为另一个。旧目录如果在模型上声明协议，读取时直接报错，不迁移。
