# 一份连接只声明一种协议

调用协议属于 Provider 配置。一份连接只声明一种协议。同一服务方案要使用另一条协议时，另建一份连接。服务方案按协议列出完整端点；选定协议后，连接地址取该端点。模型访问定义不单独声明协议。厂商只作为服务方案的命名与来源出现，不出现在字段里。

同一订阅往往要同时走 Responses、Chat Completions 与 Messages。把协议放在连接上，换协议就再添加一份连接，配置页可以按连接收起模型。OpenCode Go 的预置表已经按协议存放完整端点，连接直接使用其中一条，不从共享 `/v1` 拼接路径。

改协议后，该连接下的准入作废，指向这些访问定义的部门绑定清空。同一服务方案的另一份连接默认使用同一凭据引用，也可以改成另一个。旧目录若在模型上声明协议，读取时直接报错，不迁移。
