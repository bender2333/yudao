# 桌面客户端与 Yudao 服务分开安装，一次发布是一个 wheel

桌面客户端按 [ADR-0015](0015-desktop-client-and-http-contracts.md) 是 Electron 程序，连接一个 Yudao 服务；控制主机是一台常开的机器，客户端通常运行在用户日常使用的电脑上（[ADR-0018](0018-single-control-host-remote-execution.md)）。M1 要交给用户试用，需要确定两者怎样安装、升级与发布。开发阶段后端在代码目录里用 `uv run python -m harness api` 启动，版本随执行者的合并随时变化。2026-10-01 用户逐轮采纳推荐，决定（[设计说明](../design/client-packaging-and-release.md)）：

- Yudao 服务与桌面客户端分开安装：Yudao 服务用 `uv tool install` 安装成 `yudao` 命令，客户端用 Windows 安装程序（NSIS，按用户安装，不需要管理员权限）。两者出自同一个发布，版本号相同。
- 退出客户端不停止 Yudao 服务：客户端只在本机的服务没有运行时启动它，启动为独立的后台进程；托盘菜单有「停止 Yudao」，用本机访问方式下的专用请求停止。
- 一次发布就是一个 wheel：Yudao 服务的 wheel 内包含客户端安装程序、更新清单（`latest.yml`）、blockmap 与执行代理的安装包（约 130 MB），Yudao 服务从自己的安装目录提供它们。
- 客户端的版本跟随它连接的 Yudao 服务：接口版本不同时显示更新页，从已连接的 Yudao 服务下载同版本的安装程序更新，客户端比服务更新时降到服务的版本。使用 electron-builder 26 系列与 electron-updater 的 generic 提供方，开启 `allowDowngrade`。
- 不签名。更新配置不写 `publisherName`，列为 TODO，离开局域网或分发给他人之前加入。
- 每个试用里程碑交给用户之前发布一次，版本号按里程碑递增；发布脚本由执行者编写，架构师在架构师的电脑上本机构建，打标签并把 wheel 上传到私有仓库的 Release 作为备份。

考虑过的做法：

- 一个安装程序同时安装客户端与 Yudao 服务，由客户端负责服务的安装与升级。客户端通常不在控制主机上，控制主机上的服务以后要长时间运行、注册为系统服务（Stage 4），安装与升级由它自己的命令完成，与 `yudao-agent` 一致。
- 客户端退出时 Yudao 服务一起停止（OpenCode 桌面版的默认做法）。OpenCode 是交互式工具，Yudao 的事项要长时间运行，客户端只是看与操作的窗口。
- wheel 与客户端安装包分开，放在单独的发布目录中，控制主机上再执行一步导入。两者的版本可能不一致，升级要多一条命令。
- Electron Forge。它在 Windows 上使用 Squirrel，不支持降级，默认的更新服务只支持公开仓库；本项目的仓库是私有的，更新源又要由控制主机提供。
- 购买代码签名证书：个人开发者在中国没有可用的云签名服务，OV 证书每年约 $129 加硬件令牌 $379，而使用范围只是局域网。

理由：

- 客户端与控制主机通常不在同一台机器上，两者的安装与升级应该各自独立；同一个发布保证版本不会不一致。
- 升级控制主机只需要一条 `uv tool install --reinstall <wheel>`，客户端安装包与执行代理安装包随之一起升级，不需要另外的导入步骤，也不会出现服务与它提供的客户端安装包版本不同。
- 用户在局域网内单人使用，签名放低优先级，与认证和 TLS 一致（D29、D34）。安装与更新的路径都不经过浏览器下载，不出现 SmartScreen 警告。

后果：

- wheel 约 130 MB，`uv tool install` 时复制一次；从源码运行没有这些文件，更新源返回 404。
- 执行代理的安装包（[执行环境服务设计说明](../design/execution-environment.md)第 5.3.2 节）改为发布时构建、随 wheel 提供，不在运行时生成。
- 命令行的默认数据目录改为用户数据目录，Provider 目录文件与 `.env` 默认在数据目录内。
- 应用层与接口层设计说明第 10 节第 8 项的「附属进程」由本决定取代；`CLAUDE.md` 工作流程第 7 步在试用之前加入发布。
- electron-builder 固定在 26 系列；升级到 28 之前要先处理签名（28 起拒绝没有 `publisherName` 的更新）。
