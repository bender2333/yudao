# 候选必须经真实测试准入，未知能力不猜

上游模型列表只返回模型 ID，不返回协议、上下文窗口或工具能力，公开资料也拿不全。决定：拉回的模型是**候选**；为它建立模型访问定义必须显式指定协议；模型测试通过后才允许绑定到部门；缺的字段一律不套全局默认。

理由：Yudao 的失败代价是任务中途失败并消耗 D09 次数，宁可挡在准入之前。cc-switch 在这类场景选 fail-open（未知模型按 text+image 放行），但它的代价结构不同——它只往别的 CLI 写配置文件，不让模型跑 Agent 循环。Cherry Studio 与 LiteLLM 都不猜：前者对目录不认识的模型保留上游名、不带能力元数据，后者让用户自行挂键。

后果：模型测试必须是一次真实最小推理，不能为省成本退回连通性探测——连通性探测挡不住「凭据有效但无权调用该模型」。测试结果绑定配置修订，配置改动后旧结果只作历史。
