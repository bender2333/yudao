# 项目管理原型基线

日期：2026-09-08。此目录保存第二版项目管理原型，作为后续与第一版三部门工作台融合的设计基线。

- [原型源文件](project-management-prototype.html)：独立 HTML 片段及内存交互。
- [可打开的预览](project-management-preview.html)：由原型源文件渲染生成的浏览器包装页。
- 第一版三部门工作台仍保存在 [2026-09-06 原型](../2026-09-06/README.md)，本目录不修改其冻结文件。

## 本版范围

- 项目导航、项目概览、任务列表、资料与依据、项目设置。
- 从想法新建项目。
- 接入已有项目并展示产品、工程、质检建档结果。
- 任务下挂三部门工作区、追加指导和观测入口的融合位置。
- 置顶、搜索、重命名、归档与恢复等项目组织操作。

示例使用“货物装载规划”表示已有项目，使用“实验记录助手”表示从想法开始的项目。目录、资料和模型均为示例；原型不读取本地文件、不连接项目 API、不调用模型、不保存运行状态。

## 与第一版的融合方向

第一版的三部门循环、部门对话、Context/Provider/Prompt 检查区、请求详情和 Token 观测继续保留，挂在“项目 → 任务 → 任务工作台”下面：

1. **项目层**回答项目现在是什么、当前采用成果是什么、哪些决定仍有效、下一步做什么。
2. **任务层**承载一次具体目标及其三部门循环；总览、产品、工程、质检和观测均属于任务范围。
3. **执行与观测层**记录一次或多次 run 的实际请求、工具、响应、事件、用量和失败；只读查询不推进任务。

首页不把部门消息和 Raw 请求全部展开。项目概览只显示需要用户判断的事项、当前成果和最近任务；进入任务后显示三部门循环；从 Context 或事件再进入观测详情。这样保留第一版的信息深度，同时让长期项目演化有稳定入口。
