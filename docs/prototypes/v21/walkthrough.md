# 页面原型 V21 走查

依据：[系统总图](../../architecture.html)与[项目的组织设计说明](../../design/project-organization.md)的 4.12 至 4.15、第 5 节七份脚本，参考 `troupe` 工程蓝图控制台的节点遥测与现场步骤检视形式。

## 打开方式

用浏览器直接打开 [index.html](index.html)（支持 `file://` 与静态 HTTP 服务，不依赖网络与后端）。全部使用示例数据，刷新页面后恢复初始状态。页面顶部提供浅色 / 深色全局主题切换，右下角「场景」菜单切换典型运行情形。

项目页顶部直接展开 **5 个主标签页**：

1. **对话**：顶部列出当前事项、状态、所处轮次与当前生效 PRD 的点击入口；下方先看点阵循环蓝图，蓝图与时序图之间紧接内联 `现场窗口 · live`（或点击箭头/PRD 展开的完整差异与结构化正文），底部为包含可折叠结构化 PRD 与多题前沿决定卡片的对话线程。
2. **成果库**：集中浏览全部交付版本、PRD 修订与缺陷记录，明确区分实线绿色 `✓ 独立核验放行` 与虚线琥珀色 `◌ 开环完成：没有人核验`，展开即可查看结构化 PRD 全文（背景、目标、范围、非目标、方案、验收标准、变更说明、附注）、改动文件、彩色 Diff、逐条检验明细与工作任务摘要，并可一键回到对话与循环图中定位。
3. **组织**：直接显示组织蓝图、结构流向、四问、职能表与版本历史（含一键「换形态」与直接「改回这一条」），职责、名称与权限等自定义组织改动由进程外运维代理经通用命令行采用，不再在浏览器端维护本地草稿。
4. **事项与用量**：包含「事项列表与收敛」（项目循环健康度、资源上限与用时进度条、冻结组织比对、每项收敛判断与恢复核实入口）与「模型请求与用量」（与 `?w=` / `?dept=` 查询参数同步，按职能、状态、事项与模型筛选每次请求的上下文大小与原始输出）。
5. **设置**：在一页内保留快速操作（名称、长期目标、起始目录、加/去独立核验、换形态、观察者开关），下方直接嵌入置顶与归档、源目录、成果写回、机器授权、执行位置与 MCP 服务器配置。

## 循环蓝图与现场窗口的读法

- **深色蓝图与纸面图纸切换**：循环图右上角提供「蓝图：深色 / 蓝图：纸面」按钮，默认 `#141821` 点阵深色控制台，也可随时切到 `#fbfaf7` 纸面图对比阅读；右上方同时提供「现场窗口」收起与展开开关。
- **节点卡片信息**：每个职能节点顶部显示状态圆点与内联状态徽标（`进行中`、`等你决定`、`限流重试`、`等待回复`、`空闲` 等），中部列出当前生效模型（例如 `qwen3-coder-plus`、`deepseek-v3.2`、`glm-4.6v` 或 `内部 N 角色`），底部展示 5 格推理档位指示（`■■■■□ 高` 等；外部 agent 显示 `外部推理`）、上下文占比以及活跃时的实时 Unicode Braille `tok/s` 波形。
- **成果与询问连线**：节点之间延续实物成果流（`原文`、`PRD`、`交付 v1/v2`、`← 缺陷记录`），标明轮次与放行/打回结论；职能之间的未回答询问画作蓝色虚线；图最右侧终点区分为实线绿框 `✓ 质检放行` 与虚线琥珀框 `◌ 开环完成：没有人核验`。
- **现场窗口 · live**：位于循环图正下方（时序图上方），包含角色快切标签与六行遥测摘要（`goal`、`agent`、`context`、`touches`、`bounds`、`tokens`）。左栏逐任务列出 `读 / 写 / 运行 / 询问 / 提交` 步骤，点击任一步骤展开命令、参数、退出状态、输出与模型记录；右栏集中查看你发出的指导、待你决定的多题或单题提醒、相关成果链接，并可快捷切换指导收件人或进入职能详情。点击图上箭头、询问、消息或事项标签时，仍旧原地展开对应的差异、结构化 PRD、时序或恢复详情面板。

## 新建项目

在左侧栏点击「新建项目」或「接入已有项目」，进入独立全宽页面 `#/projects/new` 或 `#/projects/onboard`，填写项目名称、可选长期目标与起始目录（或必填源目录）后，从四张形态卡中选择起步结构：「产品 · 工程 · 质检」（默认）、「工程」、「产品 · 工程」与预览态「产品 · 工程 · 质检 · 运维」。页面不设「和某项目一样」与「高级」折叠框；系统全局页的[模型管理](#/sys/models)同步示例单轮测试简化与带代理前缀的多模态模型 `ag/gemini-3.8-flash-thinking`。

## 七份核心脚本与两个设计预览

1. **脚本一（日志清理脚本 · 外部 agent OpenCode）**：工程节点显示 `OpenCode` 与 `外部推理`；点击「清理 30 天前的日志」可对比开环外包交付差异，并在「成果库」查看虚线标记。
2. **脚本二（个人博客 · 单职能开环与加独立核验）**：单职能项目不展示多余「看经过」按钮；在「设置」点击「加独立核验」后，在跑事项继续沿用冻结旧组织，「之后新建的事项按现在的组织走」小图同步新增核验节点。
3. **脚本三（活动报名小程序 · 旁路询问）**：「产品」位于「工程」上方；切换到「工程在问产品」场景后，竖线转为蓝色询问虚线；开启「看经过」可展开时序图。
4. **脚本四（订单系统重构 · 三职能与两次打回）**：默认进入「导出订单为 CSV」，可在循环图上直接对比 `交付 v1`、`v2` 打回与质检询问产品后修订的 `PRD v2`；现场窗口展示 `orders/export.ts` 流式分卷修改步骤，切换到「订单系统重构：职能之间的询问都答完了」场景可核对已答事实与解释；从「成果库」任意卡片点击「在对话与循环图里定位」即可跳回该版本。
5. **脚本五（线上商城 · 模型限流与动作核实）**：「月度销售报表」展示模型 HTTP 429 重试等待与对应遥测；「部署到测试机」展示动作超时后进入动作核实，在「事项与用量」与现场窗口均提供直接跳转入口。
6. **脚本六（内部报表工具 · 观察者）**：观察者不在主线节点占位，而在线程与现场窗口中发出「振荡检测」决定卡；可在「设置」直接开关观察者，或进入「组织」调整读取范围。
7. **脚本七（固件升级服务 · 子组织下钻）**：「工程」节点带 `子组织` 徽标与 `看内部 ›` 按钮；现场窗口右下方与节点卡片均支持一键下钻查看 `工程架构师 → 主程 → 审查者`（及旁路 `探索者`）的内部循环蓝图与子事项 `D-1.1` 状态，点击「回到上一层」返回外层。
8. **设计预览项目（并发工作单元池、线上服务与运维）**：支持工作单元分配与槽位释放，以及运维故障从图外引入开启新事项与 `运行环境`、`成果库` 兼容呈现。
