# 原型设计变更记录 (Prototype Changelog)

本文档记录 Yudao 原型设计各版本的演化历程、核心设计决策与交互改进。

---

## [v7] - 2026-09-25

### 原型交付
- 原型文件：[v7/index.html](v7/index.html)（浏览器直接打开）
- 设计文档：[v7/design.md](v7/design.md)；构建约定：[v7/BUILD.md](v7/BUILD.md)

### 变更明细
1. **按七个阶段的路线图重新组织界面**
   - 对象分为系统、项目、事项、run、部门、角色、调用尝试与动作几层，每个界面写明读取的查询与提交的命令，真实前端随对应的后端工单逐项接入。
   - 左侧栏底部的系统分组：模型管理、运行与执行槽位、工具与扩展、元观察；节点、演化、经验三个入口只保留位置并写明所属阶段。
   - 项目标签：概览、产品、工程、质检、运维（Stage 5）、资料、观测、设置；顶栏增加事项选择框。
2. **概览的循环画面**
   - 像素风楼层：大厅、三个部门房间成环、成果库，Stage 5 加运维房间与观察台。
   - 送件小人搬运 PRD、交付箱、返工单、放行单；纸飞机表示询问与回答；排队、执行槽位、中断、待核实、待恢复、采纳竞争都有对应画面。
3. **部门房间与小人**
   - 九种角色，按部门区分衣服颜色、按角色区分配件；七十多个动作，每个动作对应一个已有事件或后续工作包的事实。
   - Stage 4 起按部门内多角色显示部门经理与固定角色的工位；画面上的数量全部来自数据。
   - 新增动作图鉴页，逐项列出动作与驱动它的事实。
4. **恢复与动作核实（3.1）**
   - 运行中、中断、待核实、待恢复、已终止五种状态；继续执行及不可用原因；动作核实与对结果未知的动作作出决定。
   - 模型引用无法使用时进入待恢复，修复配置后继续执行。
5. **模型管理按 D24 第 9 节制作**：Provider 配置卡片、编辑 JSON（格式化、重置、复制、导入、导出与校验）、候选、容量接受、推理档位声明、部门默认、部门设置弹窗。
6. **资料改为按事项只读查看**：intend、PRD、PLAN、交付、质检与 Git 差异；Stage 4 加语义记录。
7. **原型辅助工具**：阶段四档切换、标注模式、十二个场景的逐步播放。

## [v6] - 2026-09-23

### 原型交付
- 原型文件：[department-workspace-v6.html](department-workspace-v6.html)
- 设计文档：[department-workspace-v6-design.md](department-workspace-v6-design.md)

### 变更明细
1. **模型管理全局返回导航**
   - 确立模型管理为系统级全局设置定位。
   - 导航记录用户进入前的来源界面标识（如特定部门工作间或项目概览）。
   - 将模型管理页面右上角操作替换为“返回原界面”按钮，用户可随时一键返回原工作上下文。

2. **移出静态导出，引入动态 JSON 编辑器**
   - 废除原有的静态“导出 JSON”文件下载功能。
   - 增加全功能“编辑 JSON”弹窗，直接读取并展示系统当前全部供应商实例、挂载模型映射与部门基线绑定。
   - 提供 JSON 语法自动格式化、内容重置、一键复制功能。
   - 增加快速失败校验机制：提交保存时自动核验 JSON 语法与必要数据结构，发现异常就地报错阻断保存；核验通过即刻更新底层状态并全局刷新。

3. **资源卡片操作栏与添加供应商重构**
   - 将原页面顶部的“添加模型服务”操作下沉重构为“+ 添加供应商”。
   - 将“编辑 JSON”与“+ 添加供应商”两个核心操作集中放置于“已配置的模型服务”列表标题栏，紧邻“点击卡片任意区域可展开详情与模型映射”提示说明。
   - 保持折叠卡片列表与就地展开表单的视觉层次。

4. **三部门独立弹窗配置**
   - 移除部门工作间右上角原有的次级下拉菜单形式。
   - 将右上角操作统一为单体“部门设置”按钮，点击直接呼出专属的模态弹窗。
   - 在弹窗内整合三大模块：
     - 运行服务与模型访问定义（联动筛选已准入模型，配置 1 至 4 级推理思考努力程度 Effort 滑块）。
     - 部门专有系统提示词（System Prompt 规则定制与恢复默认）。
     - 协同机制（协作者子 Agent 派发许可开关）。
   - 保存后即刻同步更新部门运行基线并刷新 CRT 任务监视器展示。

5. **多项目平滑切换**
   - 侧边栏项目列表由底层项目注册表（`projects`）统一驱动渲染，支持自由切换当前活动项目。
   - 切换项目后即时同步刷新顶栏面包屑、概览页业务目标、工作区路径、成果基线、统计项以及部门 CRT 任务监视器的目标描述。

6. **消除概览行右侧滚动条**
   - 废除原 `.yp-tabs` 上设置的 `overflow-x: auto`，采用两端对齐的弹性导航容器（`.yp-tabs-header-bar`）。
   - 根绝 Windows 操作系统与 Chromium 浏览器在尺寸计算时产生的横向异常滚动条。

7. **资料与依据放置配置弹窗**
   - 在标签页导航栏右侧设立常驻的“资料与依据”配置按钮。
   - 点击后呼出专属弹窗，独立配置当前项目的原始用户需求放置位置（`INTEND.MD`）、产品需求规格说明书（`PRD.MD`）、工程事前计划（`PLAN.MD`）、质检独立验收标准（`ACCEPTANCE.MD`）以及本地工作区根目录。
   - 支持一键恢复标准规范路径，保存后即时刷新概览页依据摘要。

## [v5] - 2026-09-22

### 原型交付
- 原型文件：[department-workspace-v5.html](../archive/prototypes/department-workspace-v5.html)
- 设计文档：[department-workspace-v5-design.md](../archive/prototypes/department-workspace-v5-design.md)

### 变更明细
1. **单连接单协议规则**
   - 单个 Provider 实例仅挂载单一上游调用协议（OpenAI Responses、Anthropic Messages、Chat Completions）。
2. **预置供应商方案模板**
   - 提供 OpenCode Go、AnyRouter、StepFun、Anthropic 及自定义模板，自动填入协议、Base URL、文档地址与环境变量引用。
3. **远端模型拉取与容量参数核验**
   - 增加连通性探测与 `/models` 候选池提取功能，点击快速加入映射表。
   - 显式确认上下文窗口大小与最大输出限制数值，避免未知占位值导致压缩引擎异常。
4. **底置三部门全局基线分配**
   - 将全机全局生效的三部门模型与 Effort 思考强度分配收拢至模型管理页面最底端，作为新事项冻结基线。
