Yudao 画面总图

这一页展开总图第一节的「画面」方框与第四节「画面」的缝，写法与总图相同。画面是系统外面的一个使用方：像观察者一样只经接口读事实，操作只发现有的命令；它有自己的代码、测试与阶段，系统不等它。画面只要求诚实，不要求跟上。画面是事实的投影，不是模拟：画面上能当真的东西都能回到一条事实；关掉表演，剩下的全是事实。固定的是画面合同、播放的规矩、七种元件与诚实性；空间、场景、翻译器与画法都是填进去的内容。画面跟着定义伸缩：一个角色时是一间屋，三部门时是一层楼，子事项是屋里的一间小屋。

诚实性不说谎、能回链、开环看得见。写成测试，是画面唯一硬的验收，换画法也照过。
状态 = T( 查询快照 @ 位置 )
动作 = T( 事件 @ 位置 )
画面 = 事实层( 状态 ) ＋ 表演层( 动作, 叙事时间 ) 事实层只由状态决定；关掉表演层，事实层不变。
T
翻译：宿主的说法 → 画面的说法。状态只来自查询，画面不自己累加事件得出事实。
位置
事件时间。画面上任何一样东西都靠它回到依据的那一刻的事实；回放按它取。
叙事时间
演出来的先后。顺序与事件时间一致，最多落后一个上限。
事实层
承载事实的视觉通道：在哪间屋、亮不亮灯、牌子上的字、盖了什么章、仪表读数。
表演层
走位、待机、包裹在管道里走、说话气泡。不占事实通道，不回写。

什么能动换掉画法，诚实性不换

可以整体重写渲染技术、场景布局、表演（走位、待机、气泡）、声明表里的时长与级别、每个宿主的翻译器。重写以后诚实性测试照过，外面看不出事实有区别。
只能向后兼容画面合同的形状与取值、七种元件、视觉通道表（哪些通道承载事实）。字段只增，带版本。
换画面也不换事实只来自接口的查询；画面层不回写，命令只由壳发现有的命令；每个事实带来源；开环看得见；固定画出的只有边界、裁决点与权威关系，没有事件就没有轨迹。
定义画面里有几间屋、几个人、哪些管道、谁有盖章台，都从事项冻结的定义来。画面层的代码不写部门的名字，屋子长什么样写在声明里。

调节参数：落后上限、最短时长、时长倍率是填进去的内容，调节面板里改，不改合同。

  • 可以落后：系统加了画面不认识的部门或事件，画面画成通用的屋与小人，或者不画，测试照过；还没画的列在缺口清单里，不让测试失败。画面落后不算错，画错才算。
  • 先事实层，后表演：每加一个空间或元件，先只画事实层，状态直接换上去；走位、气泡、排队这些表演以后再补。
  • 只画已有的记录：画面的每一步都等系统先有对应的记录；系统的验收不等画面，画面的测试不挡系统的合并。
  • 设计问题用草图回答：要回答画面怎么画时，画一张假数据的单页草图，答完就扔；验收看画面合同与诚实性，不对照草图的像素。

一个事件怎样上画面先演经过，再落状态

事件到达带位置
翻成动作零个、一个或几个
按级别关键、普通、进度
排队演同一个参与方一次演一件
状态到达等位置不大于它的动作演完
上画面事实层换成这份状态，带回链
  • 关键的一定演：成果送达、打回、询问与回答、核验结论、决定送出与收到、失败。堆积时可以缩短，不丢。
  • 普通的排队：读材料、写文件、跑命令。画面落后超过上限时丢掉。
  • 进度不排队：工具调用、模型请求、输出片段合成一个持续的姿势，头顶换成最近的一项。
  • 状态等动作：状态只等已经到了、位置不大于它的动作，所以不会卡住；画面上的每个状态都是事实在某个位置上真有过的状态。
  • 落后有上限：超过就快进；正在演的关键动作加快演完，不凭空消失。
  • 跳到最新：打开画面、重新同步、从后台切回时清空时间线，直接显示最新状态，不补播；错过的经过由离开报告交代。
  • 回放：拖到哪个位置，就显示那个位置的状态。
  • 实时内容不排队：决定卡片和流式文字到了就显示，你要据此操作。

要守的缝「画面」方框里面的缝，不计入总图的十三道；画面与系统之间只有总图的「画面」那一道

已定：子架构师现在就守；未定：先别依赖。字段名由子架构师定。

画面合同已定翻译层 ↔ 画面层画面里面最要紧的一道。
  • 画面层只收状态、动作与实时内容，不导入宿主的任何代码
  • 合同里没有宿主的事件种类、查询名与状态值
  • 都带位置；画面层只传位置，不解读
读事实已定宿主 ↔ 同步层只管数据是不是最新，不管怎么画。
  • 快照带位置；事件流按位置续，有缺口就重新同步
  • 按刷新清单重查；服务端不为画面加专用的查询
  • Yudao 这一侧就是总图「画面」那道缝，经「接口」
回调已定画面层 → 壳画面看得见、点得到，自己不动手。
  • 画面只交出用户的操作：选决定、点跳转、聚焦、点开回链
  • 命令只由壳经接口发，每个可操作的物件对应一条现有命令
  • 细内容交给宿主的页面看
声明已定画面层 ↔ 场景内容加场景、加动作不改时间线。
  • 每种动作的级别、时长、谁演、走到哪写在声明表
  • 屋子、人物、管道的画法按定义里的种类取
  • 动作本身不带级别与时长
映射已定系统的概念 → 七种元件表写完，世界就定了。
  • 每个概念归一种元件，写来源、状态与变化、位置、操作、仪表、不画的部分
  • 每种事件在每个场景里翻成动作、写明不画，或者还没归类；还没归类的不画，列进缺口清单
  • 归不进去的是装饰，不作断言
宿主已定画面 ↔ 宿主同一个画面放进不同的宿主。
  • 画面是单独的应用：单独的目录、构建、测试与里程碑，以单独的页面打开
  • 只经宿主公开的接口，不导入宿主的任何代码，由导入方向的测试守住
  • Yudao 是第一个宿主：发布时带上构建好的画面，给它一个单独的地址；画面构建不过时照常发布，只是不带画面

跟着定义伸缩同一套元件，拓扑从定义推出

部门是屋，角色是小人，关注与许可关系是管道，核验角色有盖章台，子事项是屋里的一间小屋。定义变了，画面跟着变，不另写代码；没有的东西不画，不留黑着灯的空屋。

定义里填的画面规则怎样看得见
一个角色直做一间屋、一个人、出口托盘交完成盖虚线的「开环完成」章，没有放行章
几个角色直做几间屋，询问走传信管有核验角色时，它的屋里有盖章台
三部门按成果一层楼，三间屋连成环核验角色的实心「放行」章；打回走红色回流
任务池（以后）大厅的任务板，成员摘卡认领每个单元一张卡；放行仍是整份交付一次
子组织屋里一间小屋，门框上是余量与层数远看是一个在转的小盒子，推近进去；结束时收成一份提案
观察者、看门狗楼外的观察哨；机房的两个槽位观察者只看，信号送到写入口；候选失败切回稳定槽

三个空间

楼：组织部门、角色、包裹、询问、决定板、上下文刻度。来自事项的事件流。
机房：机器执行机器、部署、交付出去的软件在运行，故障冒烟。来自机器流与运维记录。
城：产品页面、接口、数据表是建筑，要求是蓝图，证据让蓝图变成建筑。只读，只能指着说话。

按什么顺序建出来见路线图第 4 节；每个空间画的都是已经存在的记录，没有记录就不画。

换宿主Yudao 是第一个宿主

画面是单独的应用，画面层不认识 Yudao，只认画面合同；Yudao 也只是经公开接口接上的一个宿主。换一个事实源只要换翻译器与壳。接外部 agent 是方向，不排期。

Yudao查询快照与事件流 → Yudao 的翻译器。部门、核验、子事项、观察者都有，画面按定义长全。
外部 agent（以后）例如 Claude Code 的会话记录与工作区的差异 → 它自己的翻译器。只有一个角色，没有核验。
同一个画面层画面合同、播放时间线、七种元件、诚实性测试
Yudao 的壳回调变成现有的命令经接口发，可以指挥；细内容链到 Yudao 的页面。
外部宿主的壳可以只看；回调怎样处理由宿主定。
  • 翻译器交出带位置的状态与动作：Yudao 的状态来自查询；别的宿主没有查询，状态由它的翻译器从记录得出。这件事在画面层外面，画面层照样不累加事件。
  • 诚实性对任何宿主都成立：每个状态能回到来源里的一个位置；来源里没有独立核验，就画开环。
  • 宿主没有的东西不画：外部 agent 没有部门与放行，画面就是一间屋、一个人、一枚虚线章。
