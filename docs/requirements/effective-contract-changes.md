# D15 有效变化与执行依据

## 来源

本会话持续输入、PRD、专家问答和上下文要求，以及用户指定的第一阶段对齐 prompt 对版本与实际执行的补充。

## 有效规则

产品记录本次改变、仍须保留、合法废止的要求及关键理由。有效合同包括当前需求和实际生效的补充决定，其内容变化影响计划、待答请求、旧交付、检查及待发工作；摘要与原始历史保留为来源，不把旧指令恢复为当前目标。

输入接纳、请求开始、工具开始、提案接纳和终态共用控制顺序。已发请求及迟到输出保持原绑定；先接纳的新输入不能被旧 release 跳过。终态后的新工作另起任务，replay 不等于继续运行。

## 状态

已有 spec 版本失效和回执绑定基础。补充决定统一标识、输入与 release 交错及完整适用性检查按 B-D 实施。
