# D03 intend.md 原文保存

## 用户原话

> 用户原始的命令和资料作为intend.md，不用任何修改，原文存储。

## 已确认

- 文件名使用 `intend.md`，不改名为 `intent.md`。
- 命令和资料按用户原文保存，不总结、润色、纠错、翻译或用 PRD 代替。
- 原始文本的空白和换行也属于原文，不做 trim 等规范化。
- 后续产品解释、需求变更和实施计划单独保存，不反向覆盖原始输入。

## 实现边界

当前原生重构将首次任务原文保存为事件事实、内容工件及 `materials/<run_id>/intend.md`，与研发可修改的交付工作区分离。每次模型请求采用对应任务的原始文本。

## 待确定

连续多次输入的分隔及非文字附件的引用方式；系统时间、处理状态等元数据不应混写成用户原文。

## 实现状态

首次任务原文在原生重构中接入；持续输入和附件流程尚待实现。
