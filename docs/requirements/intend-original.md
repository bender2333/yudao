# D03 intend.md 原文保存

## 用户原话

> 用户原始的命令和资料作为intend.md，不用任何修改，原文存储。

## 已确认

- 文件名使用 `intend.md`，不改名为 `intent.md`。
- 命令和资料按用户原文保存，不总结、润色、纠错、翻译或用 PRD 代替。
- 原始文本的空白和换行也属于原文，不做 trim 等规范化。
- 后续产品解释、需求变更和实施计划单独保存，不反向覆盖原始输入。

## 实现边界

首次任务原文保存为事件事实、内容工件及数据目录下的 `materials/<run_id>/intend.md`，与研发可修改的交付工作区分离。每次模型请求采用对应任务的原始文本。

## 本轮设计选择

连续输入依序直接拼接原始字节，逐条原文工件和字节范围保证复原；时间与状态不写入原文。首批入口仅支持文本，未支持附件类型明确报错。

活动任务中从文本入口发送的 `/stop`、`/cancel` 同样保存精确原文，再立即取消；其状态表示命令已执行，不等待产品处理。点击取消按钮只记录实际控制操作，不伪造一段用户未输入的文本。此为对“原始命令原文保存”的本轮执行选择。

## 实现状态

首次任务原文已实现，空白与换行保真已有自动化验证；持续输入待实现。首批仅支持文本，附件未支持。
