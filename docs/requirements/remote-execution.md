# D29 远程执行环境

状态：有效。依据：[总图](../architecture.html)第四节「动作」的缝与第六节「拆开部署」；部署形态见 [ADR-0018](../adr/0018-single-control-host-remote-execution.md)，机器授权与结果未知两条依据 [ADR-0038](../adr/0038-function-first-commands-without-registration.md)；设计：[执行环境服务设计说明](../design/execution-environment.md)。路线位置：[总体路线图](../program-roadmap.md)阶段四「拆开部署、细粒度协作、产品的城」（拆开与四道过网络的缝），第 3 节道 10 部署与环境、道 05 动作与工具（远程执行代理）。

## 已确认

- 可以预见的时间内只有用户一个人使用。
- 多台机器的用途是执行：工程的构建、质检的检查、运维的部署与观察，在其他电脑或树莓派一类能运行 Linux 的板子上进行。
- 控制核心、事件日志、工件存储、Provider 模块与观察者在一台控制主机上运行，控制核心只有一个实例、不做主备，事件日志继续使用 SQLite（ADR-0018）。
- 执行环境是一个服务，有两种实现：本机进程与远程机器上的执行代理（[执行环境服务设计说明](../design/execution-environment.md)第 2.1、5 节）。本机进程在控制核心的进程内直接调用，执行代理经 HTTP 加 JSON 的合同调用。用户在系统中登记机器，写明名称、地址与用途；每个项目授权使用其中的机器，写明登记的目录与是否作为本项目的运行环境，授权按项目分开（按 [ADR-0038](../adr/0038-function-first-commands-without-registration.md)：项目把这台机器设为执行位置，就能在那里执行全部动作）；只在局域网内使用期间，连接的认证与加密保留位置并标为 TODO，离开局域网之前加入访问令牌与 TLS，使执行代理只接受控制主机的请求。
- 控制主机使用一台常开的机器（台式机、小主机或树莓派），长时间运行依赖它一直开机。
- 模型凭据只保存在控制主机。
- 远程动作的存活按动作判断：执行代理在动作进行期间发送心跳，超时没有心跳时动作结果记为未知，按[恢复契约与故障矩阵](../design/recovery-contract-and-fault-matrix.md)处理：先自动核实，其余交还发出它的会话，由模型决定是否重新执行。
- 代码在执行位置上直接运行，Yudao 不提供操作系统层面的沙箱；来源不明的仓库，把项目的执行位置设到另一台登记的机器（[执行环境服务设计说明](../design/execution-environment.md)第 8 节）。

分布式部署和微服务化有助于资源调度和未来的并发能力，虽然当前不需要做，但是未来仍然是一个很好的架构；部门单独部署在原理上与单机没有区别。[ADR-0018](../adr/0018-single-control-host-remote-execution.md) 写明扩展途径：执行能力不够时增加执行环境，模型服务限流时增加连接，一台控制主机容纳不下时按项目分成多个控制核心实例；部门不作为拆分单位。

## 设计决定

- 每台机器一个机器流，与项目流一样跨版本保存（[ADR-0019](../adr/0019-project-stream-across-versions.md)）。
- 机器的上线与离线写入机器流，首页与机房按事件显示；探测的瞬时值只在实时通道显示。
- 本机进程在进程内直接调用（[ADR-0018](../adr/0018-single-control-host-remote-execution.md)）。
- 核实可以引用迟到回执作为证据，只在还没有做出决定时。
- 升级要求执行代码摘要完全相同；用户在每台机器上运行升级命令，控制主机不远程安装。
- 机器离线、需要升级时进入待恢复，问题解决后自动继续，等待时间不计入运行时间；等待机器有一个时长上限参数，超过时转为决定请求并通知用户一次。
- 执行位置上的代码可以访问外网。
- 项目没有设置执行位置时全部在本机进程运行。
- 树清单格式 `yudao-public-tree-v2` 增加可执行标记，旧清单继续可读（清单属于采纳成果，在项目流中）。
- 远程 Windows 机器在真实测试之前不支持。
- 远程执行代理的真实验收与执行代理系统服务的验收在 Orange Pi AIpro 开发板上进行（开发板的情况见[执行环境服务设计说明](../design/execution-environment.md)第 1.1 节）；验收条件：同一事项的工程构建在控制主机上完成，质检检查在这块开发板上完成。控制主机按用户当前的 Windows 11 电脑处理。
