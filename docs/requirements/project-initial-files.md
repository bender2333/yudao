# D37 新建项目的起始文件夹

状态：有效。依据：[总图](../architecture.html)第一节「一份事实」方框（起始文件夹的快照是事项的起点）；设计：[项目的起始文件夹设计说明](../design/project-initial-files.md)。路线位置：[总体路线图](../program-roadmap.md)阶段二薄片 ①「真实项目接着做」（与接入已有项目同属一个薄片），评测场景 3 用它（薄片 ②「比单个 agent 好多少」）。

## 已确认

- 新建项目时可以给出一个起始文件夹（控制主机上的路径）。它的快照是第一次采纳之前每个事项的起点，第一次采纳以后采纳成果是起点。
- 起始文件夹不建档：没有建档事项、基线核验与初始 PRD，项目来源仍是想法新建。已有项目的完整仓库仍经 `project.onboard` 接入并建档。
- 起始文件夹只在新建项目时给出，是一次性的采集；以后不能增加或替换。
- 项目的起点只在一处求出，开始事项、排队的事项与因升级重新开始的事项共用。
- 评测场景 3 的 Yudao 一侧用起始文件夹带入题目的数据文件，与 OpenCode 一侧起点相同。
