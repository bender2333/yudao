# D06 运行中追加输入的处理时机

## 用户确认

> 当前工具完成后，在下一次模型调用前由产品部处理新输入（推荐）

确认时的条件：停止/取消命令仍按立即取消处理。

## 已确认

- 追加输入先按原文保存并确认接收。
- 已启动的工具可以完成，随后在下一次模型调用前由产品处理新输入。
- 产品维护相应要求后，后续部门依据有效需求继续。
- 一个模型响应中尚未启动的其他工具，不属于必须一起执行完的“当前工具”。
- 一般补充输入与立即停止/取消分别处理。
- 输入在模型调用中到达时，响应仍保留原绑定；在执行其工具或接纳提案之前先处理输入边界。
- 输入接纳与 release 共用控制顺序，已接收待处理输入不能被旧 release 越过；终态后明确新建任务。

## 实现状态

已确认，待实现。原生内核正在建立每个模型与工具步骤的控制边界，为该交互提供基础。
