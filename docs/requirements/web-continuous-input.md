# D01 Web 持续输入任务与命令

状态：有效。依据：[总图](../architecture.html)第一节「界面」方框与第四节「接口」的缝；设计：[应用层与接口层设计说明](../design/app-and-interface.md)、[网页界面的提供与发布设计说明](../design/web-interface-and-release.md)。路线位置：[总体路线图](../program-roadmap.md)阶段一「单机诚实闭环，三道槽位立缝」。

## 已确认

- 界面是产品入口：Yudao 服务提供的网页，在浏览器中打开本机或局域网内部署的地址（[网页界面的提供与发布设计说明](../design/web-interface-and-release.md)第 9 节）。
- 界面可以输入任务和命令，任务执行中仍然可以再次输入，像 TUI 一样随时都能输入。
- 输入需要明确接收，不因系统忙碌而丢弃。
- 运行中输入的处理边界按 [D06](in-flight-input.md)。
- 命令行与界面经过同一个应用层，接口层使用 FastAPI，从本机以外访问需要认证（[应用层与接口层设计说明](../design/app-and-interface.md)第 2、6.2 节）。
- 构建好的页面文件随 wheel 发布，由接口层提供；局域网中的其他电脑打开同一个地址（[网页界面的提供与发布设计说明](../design/web-interface-and-release.md)第 9 节）。

## 设计选择

普通文本用于新建或补充当前任务；`/stop`、`/cancel` 立即取消。终态后明确新建任务。输入接收与产品处理分别可见；当前不提供任意 shell 终端。

手机和桌面均有随时返回输入框的入口。选中活动任务时，该入口表示补充输入并保持任务目标；无任务或终态时表示新任务。输入框标明提交目标，不能因重新打开输入框而把追加内容送到新任务。
