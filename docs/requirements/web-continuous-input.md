# D01 Web 持续输入任务与命令

## 用户原话

> 现在先使用web启动，web输入任务和命令，像TUI一样，随时都能再次输入。

## 已确认

- 桌面客户端是产品入口，按地址连接本机或远端的部署（[ADR-0015](../adr/0015-desktop-client-and-http-contracts.md)）。
- 客户端可以输入任务和命令，任务执行中仍然可以再次输入。
- 输入需要明确接收，不因系统忙碌而丢弃。
- 运行中输入的处理边界按 [D06](in-flight-input.md)。
- 2026-09-26 用户决定（ADR-0015）：客户端是 Electron 桌面程序，后端不提供界面文件；命令行与客户端经过同一个应用层，接口层使用 FastAPI，从本机以外访问需要认证。本条取代此前确认的「Web 是首个产品入口」。

## 本轮设计选择

普通文本用于新建或补充当前任务；`/stop`、`/cancel` 立即取消。终态后明确新建任务。输入接收与产品处理分别可见；首批不提供任意 shell 终端。此为本轮依据授权确定的选择。

手机和桌面均有随时返回输入框的入口。选中活动任务时，该入口表示补充输入并保持任务目标；无任务或终态时表示新任务。输入框标明提交目标，不能因重新打开输入框而把追加内容送到新任务。
