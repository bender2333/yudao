# D02 三部门 prompt 展示与修改

## 用户原话

> 三部门的prompt可以隐藏或者展示，也能修改。

## 已确认

- 产品、研发、验收三个部门的 prompt 均可查看、隐藏和修改。
- 隐藏仅改变界面展示，不改变实际使用内容。
- 修改应进入部门实际调用，并能回查当次采用的内容。
- prompt 不能替代代码中的工具权限、合同校验和最终放行规则。

## 待确定

修改作用于当前任务还是默认部门设置；执行中修改何时生效。不能把“随时可编辑”自行解释为立即取消正在执行的工具。

## 实现状态

已确认，待实现。现有模型输入查看功能不等于部门 prompt 编辑功能。
