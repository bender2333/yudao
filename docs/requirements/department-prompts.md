# D02 三部门 prompt 展示与修改

## 用户原话

> 三部门的prompt可以隐藏或者展示，也能修改。

## 已确认

- 产品、研发、验收三个部门的 prompt 均可查看、隐藏和修改。
- 隐藏仅改变界面展示，不改变实际使用内容。
- 修改应进入部门实际调用，并能回查当次采用的内容。
- prompt 不能替代代码中的工具权限、合同校验和最终放行规则。

## 本轮设计选择

默认修改当前任务，目标部门下一次激活生效；已发请求保留原输入。首批不建设全局默认编辑。版本与采用范围可查，影响需求的内容通过产品处理，不取消当前工具。此为本轮设计选择，不冒称此前逐项确认。

一次激活采用固定的 prompt 版本，后续工具往返不途中换版；下次激活读取当时最新版本。逐次请求和摘要记录实际采用的版本，避免将旧版本生成的材料误标为新版本。部门规则文本可编辑，主机权限与接纳条件继续由代码维护。

部门摘要的适用范围还需核对当时原文和 prompt 版本；版本改变后从完整保留的原史重建输入视图，旧摘要及其来源仍供回查。只折叠界面不产生版本更新，也不触发上下文变化。

## 实现状态

已实现三部门 prompt 折叠查看、当前任务内编辑及采用历史。一次激活固定版本，下次目标部门激活采用更新；终态编辑明确拒绝。浏览器实际编辑工程 r2 并在模型输入中核对采用，版本篡改、更新期间旧请求与摘要适用性均通过自动化验证。
