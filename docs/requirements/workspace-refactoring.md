# D14 受控删除与移动

状态：有效。依据：[总图](../architecture.html)第四节「动作」的缝（每个动作有回执）与第三节内环第 4 步；设计：[本地通用工具设计说明](../design/local-tools.md)。路线位置：[总体路线图](../program-roadmap.md)阶段一「单机诚实闭环，三道槽位立缝」，道 05 动作与工具。

正常返工与重构需要旧实现真正退出，所以工程可以删除和移动公开工作区文件。

## 有效规则

工程在当前合同与有效计划范围内，使用宿主工具删除或移动公开工作区文件；禁止越界、主机私有路径、链接穿透与静默覆盖现有目标。工具事实、原因和路径可查。替代后的旧引用、相关检查和仍有效行为由研发计划、自检及独立 QA 核对。

质量和产品不因此取得写权限。删除当前文件不删除旧交付封存。项目导入、Git 分支整合和跨 run 采用不在本条范围。

操作对象为普通文件，不递归删除目录；移动同时核验来源和目标的计划范围，目标已存在时拒绝。重构涉及的引用更新通过计划、实际修改和检查结果核对。

路径规则与公开树共用。无计划、任一端范围外、私有目录、链接和目标冲突均不能修改文件；合法前导空格按原样核对，不借名称规范化越过计划。工具记录理由和当时合同、计划；旧交付仍可恢复。

## 验收

删除和移动的验收覆盖：无计划、任一端范围外、私有目录、链接和目标冲突时都不能修改文件；工具记录的理由、合同与计划可查；删除当前文件以后旧交付仍可恢复；真实完整任务中返工与重构可以使旧实现退出。
