# D14 受控删除与移动

## 来源与本轮决定

用户指定的第一阶段对齐 prompt 建议前移受控删除和移动。正常返工与重构需要旧实现真正退出，故本轮纳入批次 E。

## 有效规则

工程在当前合同与有效计划范围内，使用宿主工具删除或移动公开工作区文件；禁止越界、主机私有路径、链接穿透与静默覆盖现有目标。工具事实、原因和路径可查。替代后的旧引用、相关检查和仍有效行为由研发计划、自检及独立 QA 核对。

质量和产品不因此取得写权限。删除当前文件不删除旧交付封存。项目导入、Git 分支整合和跨 run 采用不在本条范围。

首批操作对象为普通文件，不递归删除目录；移动同时核验来源和目标的计划范围，目标已存在时拒绝。重构涉及的引用更新通过计划、实际修改和检查结果核对。

## 状态

已实现工程删除和移动，路径规则与公开树共用。无计划、任一端范围外、私有目录、链接和目标冲突均不能修改文件；合法前导空格按原样核对，不借名称规范化越过计划。工具记录理由和当时合同、计划；旧交付仍可恢复。E 整体与桌面手机证据验证通过，真实完整任务在 F 验收。
