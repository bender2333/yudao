日期：2026-09-14。性质：2.1 开工前合同。代码未开始。依赖 B4 之后的项目内 run，不挂在裸 run 上。

## 1. 结束时是什么

固定的三轮「失败 → 通过 → 失败」样例能追到字节，搬移后只读可重算，原运行不被改写。然后再采真实项目内事项（含失败和暂停）。没有自然回归也如实报告。

成功不要求系统已经学会自我改进。

## 2. 三层

| 层 | 责任 | 不做 |
| --- | --- | --- |
| 证据 | 把已结束的项目内 run 收成可搬移证据包 | 加载时不执行交付、不调模型 |
| 评价 | 用事先固定的主机检查在独立副本上复核 | 不改写原 QA 或 run 终态 |
| 分析 | 问题轨迹、批次分母、成本 | 不补造缺失观察 |

查询只生成投影。2.1 不创建新事项。

## 3. 归属

证据包、问题轨迹和基线挂在**项目内的 run** 上：`project_id` + `work_item_id` + `run_id`。未见任务 = 同一评价项目里的新事项，或专门的评价项目；材料与校准任务隔离。跨项目复用经验不在 2.1。

## 4. 首个任务族与检查

沿用文本处理：逐行输入/输出、空输入、合法改方向。公开检查写在材料清单里，评价不得加隐藏业务。主机检查只跑可信本地 Python，不接受任意 shell。

评价器身份、比较规则版本写入证据包。采样与成本：每次实际模型请求、检查秒数、复核经过时间分开；缺失不填零。

## 5. 证据包

目录自包含。入口含协议版本、材料来源、复核身份、有序轮次、完整文件清单。来源缺失或篡改（改 stdout 不改清单、越界路径、重复键）明确失败。加载不执行交付。

身份四分：材料声明、一次复核、内容标识、来源依据。不能互相替代。

## 6. L1 / L2 / L3

- L1：保存、搬移、只读加载、重算轨迹。
- L2：本地材料清单驱动多轮独立复核；缺失、超时、QA 依据不足保持原状态。
- L3：多份已核验证据批次统计；重复包不重复计分；重评成本与来源分开。

固定真实重复错误场景后再采真实任务。2.2 / 2.3 必须用这份基线的未见任务证明收益。
