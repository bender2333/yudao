## 本批范围

落实 `docs/grok-contract-review-task.md` 第 1、4 项：

- 产品回应 Ask 后，后续工程和质检能获得当前有效决定的实际含义。连续多个 Ask 不能只剩最后一个“接受 A”。不注入完整 transcript，不无条件追加全部历史。
- 新 spec、返工和新交付替换发生时，区分当前有效交付与用于修复的历史依据；历史工件不以无状态的当前工件身份进入上下文。

遵守总设计的状态、会话与执行分层。控制层决定产品合同是否有效，不让 LLM 直接改变投影。保持简单，不引入知识图谱或经验库。
