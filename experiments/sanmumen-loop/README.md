# 三职能互检循环（最小原型）

独立实验，不是 Yudao 设计说明，也不改本体。仓库里没有找到「三木门」这个专名；本原型按默认形态 `three_departments` 的三职能（产品 / 工程 / 质检）和语音里「部门之间质询、挑刺、相互检查并转起来」来做最小可跑循环，再和一次交付的单引擎对照。

## 跑法

```bash
python3 loop.py
```

使用确定性脚本引擎，不调用模型。结果写到 `run-log.json`。

## 任务

同一道固定题：实现 `clamp(x, lo, hi)`，`lo > hi` 必须抛 `ValueError`，不得默默交换两端。
